# IP授权流程（番茄小说/IP库为例）

> **用途**：想改编网文/小说/漫画时，必须走官方授权，**严禁喂未授权原文给AI**（已有判赔案例）
> **责任人**：producer + fact-checker | **周期**：申请~下证 7-30天

---

## 番茄小说 IP 库官方申请流程

### 1. 资格准备
- [ ] **主体资质**：公司营业执照/个体工商户/个人实名认证
- [ ] **过往作品**：≥1部已完结/已上线短剧/网剧/动画（链接+数据）
- [ ] **团队配置**：编剧/导演/制片/后期/运营 完整链路
- [ ] **合规承诺**：签署《IP改编合规承诺书》《保密协议》

### 2. 选题与申报
```
登录「番茄开放平台」→「IP授权专区」→ 浏览可授权书单
筛选条件：题材匹配/字数/完结状态/粉丝基数/改编潜力
```
- **重点书单标签**：都市高武/玄幻/系统/重生/豪门/悬疑/古言/现言
- **避坑**：连载中/版权纠纷/已授权他方/大IP(竞争激烈/改编费高)

### 3. 提交申请材料
| 材料 | 要求 |
|------|------|
| 改编企划书 | 世界观/人物/分集大纲/看点/商业价值/分发计划 |
| 核心剧本大纲 | 前3集详细/全季脊梁/爽点分布/改编变动说明 |
| 主创团队简历 | 编剧/导演代表作/获奖/平台数据 |
| 预算与排期 | 总成本/单集成本/拍摄周期/上线时间节点 |
| 运营推广方案 | 平台/投放/预期ROI/衍生开发 |

### 4. 审核与签约
- **初审**：3-5个工作日（题材/团队/合规）
- **复审**：5-10个工作日（剧本/预算/运营）
- **签约**：授权合同/改编许可/分账比例/违约条款
- **授权范围**：短剧/动画/有声书/周边/游戏/海外（按需勾选）

### 5. 授权费用（⚠️ 2026-10-10 修正）

> **重要更正**：早前本表列了「头部 IP ¥50-200 万」等区间——**与项目已核实结论冲突，且无来源**。
> `短剧方法论-v1.md` 的口径是：**番茄 IP 库开放 50 万+ 作品、免费改编，头部 IP 改编费平台 100% 补贴**。
> 以下为**修正后的口径**：

| 渠道 | 授权费 | 分账 | 说明 |
|------|--------|------|------|
| **番茄 IP 库** | **免费改编**（平台补贴） | 免费渠道约 90% 收益给版权方 | 【已确认·方法论】个人可申请，1 长 5 短/月 |
| 其他付费 IP（阅文/晋江等） | **【无项目内来源】** | 需谈 | ⚠️ 用前必须回官方源，不要照抄任何二手区间 |
| 自有原创 | ¥0 | 100% | 版权登记/商标保护见下文 |

**我们策略**：首期走**番茄 IP 库免费改编**（成本最低、平台有补贴），不做付费 IP 采买。

> ⚠️ **此前写入的「¥50-200 万 / ¥5-20 万 / ¥0-5 万」授权费区间与「7-30 天流程时限」已删除**——
> fact-checker 核查（2026-10-10）确认它们**无项目内来源、且与免费改编结论冲突**。
> 若后续确需付费 IP，**回官方源重新核实**再补此表。

### 6. 生产合规要求（合同强制条款）
- [ ] **不得篡改核心设定/人设/价值观**（需原著方复核）
- [ ] **不得植入违规/低俗/政治敏感内容**
- [ ] **必须显著标注"改编自番茄小说《XXX》作者XXX"**
- [ ] **上线前送审**：成片送原著方/平台复核（通常 3-5天）
- [ ] **数据回传**：播放/付费/分账数据实时/月度对账

## 自有原创IP建设（长期护城河）

### 1. 原创世界观注册
- [ ] **剧本/大纲/设定集**：版权登记(中国版权保护中心/地方版权局)
- [ ] **人物/地名/术语/口号**：商标注册(第41类教育娱乐/第9类软件/第25类服装)
- [ ] **视觉设定/概念图**：美术作品版权登记
- [ ] **系列标识/Logo/口号**：商标全类保护

### 2. IP 资产化运营
| 阶段 | 动作 | 产出 |
|------|------|------|
| 短剧上线 | 同步发布小说/有声书/漫画化 | 多端分发/流量互导 |
| 粉丝积累 | 社群/粉丝团/周边预售 | 核心用户资产 |
| IP授权出海 | 短剧/动画/游戏/周边/真人剧 | 多元化变现 |

### 3. 保护与维权
- [ ] **建立侵权监控**：全网爬虫/关键词/图片指纹/剧本相似度
- [ ] **证据固化**：区块链存证/公证/时间戳/Git历史
- [ ] **维权流程**：警告函→律师函→诉讼/平台投诉/行政举报
- [ ] **授权管理**：合同台账/到期提醒/续签/违约追责

## 避坑指南

| 坑 | 现象 | 规避 |
|----|------|------|
| 喂未授权小说给AI | 直接把网文喂给大模型生成剧本/分镜/提示词 | **绝对禁止**，已有判赔2万案例，**必须走官方授权** |
| 授权范围不清 | 只签短剧，后做动画/游戏被索赔 | 合同明确列举所有权利类型/地域/期限 |
| 分账不透明 | 平台扣费黑箱/原著方不给数据 | 合同约定实时API对账/月度对账/审计权 |
| 原著粉炸锅 | 改编魔改/人设崩坏/核心设定篡改 | 核心设定红线写进合同/原著方送审/粉丝共创 |
| 版权纠纷连环 | 同一IP多人授权/转授权/子授权混乱 | 独家/非独家明确/禁止转授权/备案公示 |

## 快速启动检查表（新系列立项前）

- [ ] 确定题材 → 在番茄/晋江/掌阅搜 3-5 本备选 IP
- [ ] 核对授权状态 → 可授权/未独家/无纠纷
- [ ] 试读/拆解 → 确认改编可行性/爽点/可拍性
- [ ] 提交申请 → 按流程走完审核签约
- [ ] 拿到授权书 → 立项开工/备案/生产
- [ ] 版权登记 → 原创部分同步登记/商标布局
- [ ] 上线送审 → 原著方/平台复核通过再发布
