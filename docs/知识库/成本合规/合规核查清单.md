# 合规核查清单

> **用途**：每集生成前、发布前必查 | **责任人**：producer + fact-checker | **零遗漏红线**

---

## 生成前核查（送生成前必须全绿）

### 1. 版权/IP 合规
- [ ] **剧本原创** 或 **已获授权改编**（番茄IP库官方申请通过/自有原创/公共领域）
- [ ] **人物/地名/机构** 无真实对应侵权风险（fact-checker 核实）
- [ ] **提示词中无直接引用受版权保护的文本/台词/设定**
- [ ] **参考图来源合法**：自有生成/CC0/已授权/已购买/合成自合法素材
- [ ] **音乐/音效/BGM**：自有版权/CC0/商用授权平台(ACE-Step/昇腾/网易云商用库)
- [ ] **字体/素材/插件**：商用授权/开源协议兼容(MIT/Apache2.0/CC0)

### 2. 肖像权/声音权
- [ ] **真人出镜/配音**：已签署《肖像权授权书/声音授权书》（¥500-1500/人）
- [ ] **AI生成人脸**：不模仿特定真人/公众人物（避免深度伪造风险）
- [ ] **声音克隆**：仅用授权音色/自有录制/商用授权TTS音色

### 3. AI 生成标识（合规.md 硬要求）
- [ ] **视频内显式标识**：首帧/末帧/角标任一处加"AI生成"，字号≥24px，对比度≥4.5:1
- [ ] **文案标识**：标题/简介/话题含"#AI生成 #AI短剧 #AI创作"
- [ ] **平台原生标识**：抖音/快手/B站/视频号/小红书发布时勾选"AI生成内容"

### 4. 备案合规（微短剧三类备案）
- [ ] **剧本备案**：广电/网信部门备案号（按《微短剧发展管理办法》）
- [ ] **拍摄备案**：涉外/涉军/重大题材额外备案
- [ ] **发布备案**：上线平台备案/算法备案（平台通常代办）

### 5. 内容安全红线
- [ ] **无政治敏感**：国家制度/领导人/历史/领土/民族/宗教
- [ ] **无违法内容**：赌博/诈骗/毒品/枪支/暴恐/传销/非法集资
- [ ] **无色情/低俗**：软色情/暗示/擦边/未成年性暗示
- [ ] **无暴力/血腥**：过度渲染/自残/虐待/猎奇
- [ ] **无医疗/金融违规**：虚假疗效/荐股/非法集资/伪科普
- [ ] **无封建迷信**：算命/风水/符咒致富/因果报应(改"心理/巧合")
- [ ] **未成年人保护**：无诱导充值/不良引导/身心伤害/隐私泄露

### 6. 平台特定合规
| 平台 | 特殊红线 |
|------|----------|
| 抖音 | 解说剧本类AI内容被激励排除/标识必加/版权打击重 |
| 快手 | 封建迷信/伪科普/医疗/诱导分享/营销号判定严 |
| B站 | 低质AI被喷/版权二创授权/弹幕违规连带责任 |
| 视频号 | 诱导分享封号/私域违规/营销号判定/选品翻车 |
| 小红书 | 引流违规/虚假宣传/审美不够/选品翻车/种草比例 |

## 发布前核查（上线前必须全绿）

### 1. 成片技术规格（验收标准 L3）
- [ ] **分辨率**：1080×1920 (9:16)
- [ ] **编码**：H.264 / H.265
- [ ] **音频**：AAC 32kHz 立体声
- [ ] **响度**：-14 LUFS (±1)
- [ ] **帧率**：≥30fps (建议 30/60)
- [ ] **码率**：≥5Mbps (1080p)

### 2. 字幕/对白校验
- [ ] **ASR 校验通过**：`python scripts/verify_asr.py` 相似度 ≥90%
- [ ] **字幕安全区**：底部 1/3 无遮挡关键画面（MarginV ≤260）
- [ ] **字幕规范**：简体/半角标点/无错别字/时间轴对齐真实文件时长
- [ ] **AI标识字幕**：含"AI生成"字样，时长≥3秒

### 3. 平台发布配置
- [ ] **标题**：含核心关键词/搜索词/情绪钩子/≤30字
- [ ] **封面**：1080×1920，高清/有张力/含标题文字/无水印
- [ ] **标签/话题**：3-8个精准垂类标签+1-2个热门大标签
- [ ] **简介**：含剧情梗概/人设/制作团队/AI标识/引导互动/合规声明
- [ ] **定时发布**：按平台黄金时段(见分发策略卡)
- [ ] **同步分发**：多平台同步/差异化标题封面/统一备案号

### 3. 数据留证（合规.md §二 - 判案核心证据）
- [ ] **提示词原文**：逐镜完整保存 `docs/生成留证/<系列>/<EP>/prompts.md`
- [ ] **生成参数**：模型/种子/时长/分辨率/参考图路径 `params.json`
- [ ] **中间产物**：原始mp4/废片/重抽版本 `_validate/shots_real/`
- [ ] **修改记录**：剧本/分镜/提示词的 Git 历史/修订日志
- [ ] **校验报告**：Gate检查输出/ASR报告/抽帧截图 `verification/`

## 违规应急预案

| 场景 | 1小时内动作 | 24小时内动作 | 责任人 |
|------|-------------|--------------|--------|
| 版权投诉/下架 | 立即下架/保留证据/内部溯源 | 律师函回复/申诉/整改报告 | producer |
| 肖像权投诉 | 立即下架/联系当事人/删除素材 | 赔偿协商/授权补签/流程修正 | producer |
| 平台违规限流/封号 | 停止发布/自查清单/申诉材料 | 整改报告/合规培训/账号养护 | traffic-strategist |
| 舆情/负面舆论 | 不回应/不删评/内部研判 | 官方声明/澄清/危机公关 | producer |
| 数据泄露/隐私投诉 | 立即隔离/通知用户/上报 | 合规整改/技术加固/法律应对 | fact-checker |
