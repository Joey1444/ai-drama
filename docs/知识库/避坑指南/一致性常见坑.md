# 一致性常见坑避坑指南

> **来源**：项目实测(T2VA跨镜漂移2倍/M09跑偏) + 方法论§7.2 + 升级路线.md + waoowaoo/Jellyfish 经验 + 事实基线.md
> **核心认知**：**模型无跨镜记忆**，T2VA 逐镜独立生成，**一致性只能靠外部锚点**（关键帧/参考图/后期归一/LoRA）

---

## 🔴 致命级

### 1. 纯 T2VA 指望跨镜一致
- **现象**：同一场景不同镜头砖墙颜色不同/光照色温漂移/角色五官漂移/服装细节变化
- **根因**：T2VA 逐镜独立生成，模型无跨镜记忆（方法论§7.2 头号杠杆是 image-to-video）
- **实测证据**：M01 vs M05 老巷砖墙暗红 vs 灰青，M07 色温偏暖，M06 未按提示词执行
- **修复**：**必须上关键帧链路**——T2I 关键帧 → I2VA
- **预防**：分镜阶段就标注每镜 `输入参考图：REF-首帧/REF-身份`，禁用「无（文生视频）」用于需一致性的镜头

### 2. 定妆帧抽错（非正脸/非闭嘴/有遮挡）
- **现象**：后续参考式镜头脸型崩坏/嘴巴张开/遮挡物烙印在脸上
- **根因**：参考式会把参考图特征"咬进"后续生成，错误参考图=错误放大
- **修复**：pick_frame.py 严格按标准抽帧：**正脸五官清晰·嘴唇闭合·光照均匀·无第二人·不糊**
- **预防**：自动化抽帧校验脚本 + 人工二次确认

### 3. 说话帧当定妆帧
- **现象**：张嘴状态被固化，后续镜头嘴巴僵硬/张闭异常
- **根因**：说话瞬间面部肌肉张力与静态不同，参考式会复制该状态
- **修复**：**严禁抽说话帧**，必须抽「正脸闭嘴」静态帧（方法论§7.2/§3-A5）
- **预防**：pick_frame.py 自动检测嘴唇闭合度

### 4. 身份参考图分辨率太低/压缩伪影
- **现象**：后续镜头脸部模糊/伪影/细节丢失
- **根因**：H3 参考图建议 ≥512×512，压缩伪影会被放大
- **修复**：关键帧用 Qwen-Image 出 928×1664 原图，无损 PNG 传参考
- **预防**：参考图规格标准化：PNG/无损/≥768px短边

### 5. 多角色同框（H3 硬禁令）
- **现象**：双人对话/群戏直接崩坏/融合/消失
- **根因**：H3 多角色同框是最不可靠项，**直接崩**（制作红线§1）
- **修复**：剧本/分镜阶段就按红线设计——**单人情绪镜头/屏中屏/过肩/空镜替代**
- **预防**：check_script.py 自动校验同框风险

## 🟠 严重级

### 6. 场景/环境跨镜漂移（曝光/色温/几何）
- **现象**：同一地点不同镜头曝光亮度跳变/色温冷暖漂移/墙面纹理/几何结构不一致
- **根因**：无共享场景锚点，每镜独立采样
- **修复**：
  - 方案A：关键帧链路（场景首帧 T2I → 后续 I2VA）
  - 方案B：后期归一（ffmpeg/Davinci 曝光/色温/曲线匹配）
  - 方案C：场景参考图（同一场景首镜出图 → 后续镜头 Ref2VA scene role）
- **预防**：分镜标注 `场景锚点：REF-场景首帧`，同场景镜头共享

### 6. 角色造型/服装/道具跨镜漂移
- **现象**：衣服领型/颜色/纹理变化/道具出现消失/形状变化
- **根因**：无造型/道具参考图锚定
- **修复**：
  - 关键造型/道具单独出图（Qwen-Image）作参考
  - 服装/道具状态在视觉设定.md 连续性锁定
  - 分镜标注 `输入参考图：REF-服装/REF-道具`
- **预防**：视觉设定.md 建立「造型状态/道具状态」连续性锁

### 7. 光照/阴影/阴影方向不一致
- **现象**：同一场景不同镜头主光方向/阴影长短/硬度不一
- **根因**：提示词中光照描述不统一/无共享光照参考
- **修复**：
  - 统一提示词光照描述：`low key + motivated light + practical light only`
  - 场景首镜出图确立光照基调 → 后续镜头 Ref2VA scene role 继承
  - 后期统一色调曲线/阴影提升
- **预防**：视觉设定.md 锁定「布光方案/色调/光源位置」

### 8. 缺乏重抽/筛选机制
- **现象**：烂片直接用上/漂移帧未剔除
- **根因**：认为一次生成必须完美，无重抽预算/流程
- **修复**：**小批量先试，只重跑坏的**（方法论§7.2），预留 1.5x 重抽预算
- **预防**：生产流程强制「出片→抽帧检查→打标→坏镜重抽→再检」

## 🟡 一般级

### 9. 后期归一参数不标准化
- **现象**：每集后期参数不同/人工主观调色/无法复现
- **修复**：建立项目级 LUT/色调曲线/曝光基准/响度标准（-14 LUFS），脚本化应用
- **预防**：build.py 集成标准化后期管线

### 10. LoRA 训练时机/数据/参数不对
- **现象**：LoRA 过拟合/欠拟合/污染基础模型/推理慢/多角色互相污染
- **修复**：
  - 触发条件：漂移>30% 或 跨集复用角色 ≥3集（升级路线.md）
  - 数据：20-50张高质量一致性图/多角度/多表情/多光照
  - 参数：Rank 32/Alpha 16/步数 1000-2000/LR 1e-4
  - 多角色：分角色训练/推理时分别加载/不混合
- **预防**：LoRA 训练 SOP 文档化

### 11. 参考图版本管理混乱
- **现象**：用了旧版定妆帧/错误版本场景图/被覆盖的参考图
- **修复**：参考图命名规范 `REF-<角色/场景/道具>-<版本>-<日期>.png`，Git LFS 管理
- **预防**：scripts/collect_shots.py 自动校验参考图版本

## 关键帧链路 SOP（T2I → I2VA）

```
分镜完成
    ↓
short-drama-image-prompts 生成《图片提示词.md》（定妆/首帧/场景/道具）
    ↓
RunPod 同 Pod 跑 Qwen-Image (T2I) 出所有关键帧
    ↓
pick_frame.py 校验关键帧质量（正脸/闭嘴/清晰/无遮挡/光照均匀）
    ↓
short-drama-video-prompts 生成《视频提示词.md》（Ref2VA/I2VA 模式，绑定 REF 槽位）
    ↓
RunPod 跑 H3 I2VA/Ref2VA 生成视频
    ↓
抽帧检查 → 坏镜重抽 → 后期归一 → 成片
```

**成本**：单集关键帧 GPU 成本 < $0.5（升级路线.md §4），同 Pod 零新平台。
