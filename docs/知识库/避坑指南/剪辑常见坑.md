# 剪辑常见坑避坑指南

> **来源**：项目实测 + build.py/make_edit.py/make_srt.py 实战 + ffmpeg/libass 坑 + 方法论 + 短剧方法论§6/§12
> **核心原则**：**剪辑参数零手写——全部从分镜自动推导**，人工只做创意决策

---

## 🔴 致命级

### 1. xfade 转场导致时间轴前移，字幕不同步
- **现象**：每过一个转场，后续镜头起点前移，字幕逐渐提前，结尾字幕严重脱轨
- **根因**：`xfade` 消耗重叠时长，后续镜头在时间轴上前移，但字幕按原始时长累加
- **实测**：13镜 xfade 累计前移近 7 秒
- **修复**：`make_edit.py` 计算剪辑点时**必须减去 xfade 重叠时长**，字幕时间轴基于**探测真实文件时长**而非请求值
- **预防**：build.py 强制 `ffprobe` 读取每个片段真实 duration，据此生成 edit.json 和 SRT

### 2. H3 标称时长 ≠ 实际时长（17帧网格取整）
- **现象**：请求 4s 实际 4.459s (107帧)，13镜累计差近 7 秒
- **根因**：H3 时长按 17帧网格取整，非整数秒
- **修复**：**字幕/时间轴必须探测真实文件**，`ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 file.mp4`
- **预防**：collect_shots.py / build.py 强制实测时长入库

### 3. ffmpeg `subtitles=` 滤镜 `original_size` 不生效
- **现象**：字幕字号巨大/超出画面/位置错乱，`original_size=1080x1920` 完全不生效
- **根因**：libass 仍按默认 PlayRes(384×288) 换算字号，`FontSize=68` 被放大到约 24% 画高
- **修复**：**改用 `.ass` 文件，在 `[Script Info]` 写死 `PlayResX: 1080` `PlayResY: 1920`**
- **预防**：make_srt.py 直接输出 `.ass` 而非 `.srt`，build.py 用 `ass=` 滤镜

### 4. `MarginV ≥ 300` 或加 `Alignment` 导致整条字幕不画
- **现象**：字幕莫名其妙全消失，无报错
- **根因**：libass 渲染逻辑缺陷，MarginV 过大或显式 Alignment 触发静默失败
- **修复**：**MarginV 别超 260、别加 Alignment**，位置用 `{\pos(x,y)}` 精确控制
- **预防**：make_srt.py 强制 MarginV=200，禁用 Alignment 字段

### 5. 测试 ffmpeg 输出用 `/dev/null`（Windows 不认）
- **现象**：命令报错/无输出/静默失败
- **根因**：Windows 无 `/dev/null` 设备
- **修复**：用 `-f null -` 或给标准扩展名（如 `test.mp4`）
- **预防**：所有 ffmpeg 命令跨平台兼容性测试

## 🟠 严重级

### 6. 滤镜里盘符冒号未转义
- **现象**：Windows 下 ffmpeg 报错 "No such file or directory"
- **根因**：滤镜链中 `C:\path\file` 冒号被当作滤镜分隔符
- **修复**：盘符冒号转义 `C\:/path/file` 且整条滤镜链**包单引号**
- **预防**：make_edit.py 自动处理路径转义

### 7. J-cut/L-cut 判断错误导致人声重叠/断裂
- **现象**：上一镜尾音与下一镜头音重叠/画外音被切断/环境音突兀
- **根因**：`make_edit.py` 判断逻辑：画外音→J-cut，**但前一镜有台词时不 J-cut**（否则人声重叠）
- **修复**：逻辑优化：
  - 当前镜有画外音 AND 前镜无台词 → J-cut (提前 0.3-0.5s 进音)
  - 当前镜有台词 → 硬切/淡入淡出
  - 末镜台词 → 静音刀 (干净收尾)
- **预防**：单测覆盖所有组合

### 8. 字幕遮挡关键画面（脸/手/道具/文字）
- **现象**：字幕盖住嘴巴/手持道具/屏幕文字/关键动作
- **根因**：固定底部位置，未考虑画面安全区
- **修复**：
  - **底部 1/3 留给字幕与平台 UI，关键信息不放进去**（H3提示词.md §竖屏构图）
  - 动态位置：检测画面下半区人脸/手部/高频区域，字幕上移/分行
  - 竖屏构图：主体压中轴，关键信息在上半部
- **预防**：make_srt.py 集成安全区检查（可选）

### 9. 响度不统一，平台审核不通过/用户体验差
- **现象**：有的镜大有的小/开头结尾音量跳变/平台限流
- **修复**：**全片响度标准化 -14 LUFS**（EBU R128），`loudnorm=I=-14:TP=-1:LRA=11`
- **预防**：build.py 最后一步强制 loudnorm

### 10. BGM 循环点有爆音/断裂/节奏不对齐
- **现象**：BGM 循环处有爆音/节奏断层/与画面节奏点不对齐
- **修复**：
  - 零交叉点循环/淡入淡出 50ms
  - 节奏点对齐：`make_edit.py` 提取分镜「声音」列低频/轰鸣标记 → BGM 重音对齐
  - ACE-Step 生成时指定 BPM/结构/循环段
- **预防**：BGM 生成规范文档化

## 🟡 一般级

### 11. 剪辑节奏纯靠感受，无分镜依据
- **现象**：剪辑点随意/节奏拖沓/爽点被切弱
- **根因**：未按分镜「声音/画面/运镜」推导剪辑点
- **修复**：`make_edit.py` 全自动推导：
  - 场景边界 → dip
  - 声音列含低频/轰鸣 → 低频垫底区间
  - 画外音 → J-cut (前镜无台词时)
  - 末镜台词 → 静音刀
- **预防**：分镜必须标注「声音/运镜/景别」字段

### 12. 转场过度/花哨破坏叙事
- **现象**：到处 xfade/旋转/推拉/特效转场，像 PPT/模板感
- **修复**：**只用 xfade 淡入淡出**，时长 0.3-0.5s，场景转换才用 dip to black/white
- **预防**：风格指南固化

### 13. 末尾没有"静音刀"，尾音拖沓
- **现象**：最后一句台词后拖着环境音/音乐/静默，不干净
- **修复**：末镜有台词 → 台词结束即硬切静音（静音刀）
- **预防**：make_edit.py 规则固化

### 14. 多尺寸输出无自动化
- **现象**：手动导出 9:16/1:1/16:9/4:5，易错漏
- **修复**：build.py 一次性输出全规格，`clippyme`/`ffmpeg` 自动裁剪+人脸追踪
- **预防**：输出规格清单标准化

## 自动化管线（零手写参数）

```bash
# 1. 分镜 → 剪辑参数
python scripts/make_edit.py "docs/方案/<系列>/08-<EP>分镜.md" --clips _validate/shots -o _validate/edit.json

# 2. 视频提示词+剧本+分镜+成片 → 字幕
python scripts/make_srt.py "docs/方案/<系列>/09-<EP>视频提示词.md" \
  --script "docs/方案/<系列>/06-<EP>剧本-定稿.md" \
  --shots _validate/batch/shots.json \
  --edit _validate/edit.json \
  --clips _validate/shots \
  -o _validate/subs/subtitle.ass

# 3. 一键成片（含响度/规格/字幕/转场）
cd _validate && python build.py edit.json
```

**产物**：`_validate/out/final.mp4` (1080×1920 / h264 / aac 32kHz / -14 LUFS / 含字幕)

## 关键 ffmpeg 模板（已验证）

```bash
# 字幕烧录（.ass 格式，PlayRes 写死）
ffmpeg -i in.mp4 -vf "ass=subtitle.ass" -c:a copy out.mp4

# 响度标准化
ffmpeg -i in.mp4 -af "loudnorm=I=-14:TP=-1:LRA=11" -c:v copy out.mp4

# xfade 转场（时长 0.4s，offset 需按实际时长计算）
ffmpeg -i 1.mp4 -i 2.mp4 -filter_complex \
  "[0:v][1:v]xfade=transition=fade:duration=0.4:offset=4.059[v]" \
  -map "[v]" -map 0:a? -map 1:a? -c:v libx264 -c:a aac out.mp4

# 探测真实时长（字幕/时间轴必用）
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 file.mp4
```
