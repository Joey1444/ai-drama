# 部署常见坑避坑指南

> **来源**：RunPod 实测(H3-RunPod实操手册) + 事实基线.md + Toonflow/Jellyfish/shortdrama-pipeline 部署经验 + 升级路线.md
> **核心原则**：**自动化/可复现/可监控/成本可控/忘停保护**

---

## 🔴 致命级

### 1. RunPod 建 Pod 忘加 `allowedCudaVersions:["13.0"]` → CUDA 起不来/驱动版本不匹配
- **现象**：Pod 启动后 `nvidia-smi` 报错/ComfyUI 无法识别 GPU/模型加载失败
- **根因**：RunPod 默认 CUDA 版本可能不兼容 H3 模板依赖的 13.0
- **修复**：**建 Pod 必须强制指定** `"allowedCudaVersions": ["13.0"]`
- **预防**：部署脚本/模板硬编码此参数

### 2. SSH 公钥只在创建 Pod 时注入，重启失效
- **现象**：Pod 重启后 SSH 连不上/公钥消失/被迫重建 Pod
- **根因**：RunPod SSH 公钥**只在创建时注入**，重启不持久化
- **修复**：
  - 方案A：不重启 Pod，长任务跑完再停（推荐）
  - 方案B：启动脚本里自动重配 SSH（`/etc/ssh/sshd_config` + `authorized_keys`）
  - 方案C：用 RunPod CLI `runpodctl pod start` 而非网页重启
- **预防**：部署文档标注"严禁网页重启 Pod"

### 3. ComfyUI 进度条走 `\r`，`tail` 看不到 → 误判卡死/误杀正常任务
- **现象**：`tail -f log` 一直没输出/进度条卡在 0%/等 25 分钟以为挂了强行杀掉
- **根因**：进度条用 `\r` 回车符刷新同一行，`tail` 默认按换行符输出
- **实测**：任务实际 30 分钟后正常出片，**差点误杀一条正常任务**
- **修复**：**查看日志用 `tail -c 3000 log | tr '\r' '\n'`** 或 `pod_wait_queue.sh` 监控队列
- **预防**：监控脚本集成正确日志查看方式

### 4. 忘 Stop Pod → 一夜烧 $10+/月烧 $500+/数据丢失
- **现象**：任务跑完/报错/周末忘关，Pod 持续计费/网络卷持续计费
- **根因**：RunPod 按秒计费，**无自动停机/无预算告警默认开启**
- **修复**：
  - **强制自动停机脚本**：任务队列空闲 N 分钟 → 自动 `curl -X POST .../pods/<id>/stop`
  - **预算告警**：RunPod 设置预算上限/邮件通知
  - **收尾清单**：每次生产结束必须执行停机确认
- **预防**：`pod_wait_queue.sh` 集成空闲自动停机，收尾流程强制人工确认

### 5. 网络卷停机也计费/容量不足/误删
- **现象**：Pod 停了但网络卷还在扣费/模型下不下/重要文件丢
- **根因**：RunPod 网络卷**停机也计费**($0.07/GB/月)，建 Pod 时若不挂载/容量不足/误删卷
- **修复**：
  - 模板自带 110GB 卷，**不用建网络卷**（模板已含模型缓存目录）
  - 如需额外存储：建最小卷/挂载到 `/workspace/extra`/定期清理/备份重要文件
  - 重要文件（模型/参考图/成片）本地备份 + Git LFS
- **预防**：部署清单核对卷配置

## 🟠 严重级

### 6. Pod 权重可能与预期不符（**先查再断言**）
- **现象**：以为只有 FL2VA、参考式跑不了；或反之以为有 T2I 其实没有
- **根因**：Pod 的**本地卷**内容会随时间变化（后继补下了模型），文档记录会过期
- **实测（2026-10-10）**：该 Pod **FL2VA 与 Ref2VA 均已就位**（各 20G）；但 **`checkpoints/`、`diffusers/` 全空 → 没有任何 T2I 模型**
- **修复**：**动手前先 `ls` 模型目录**，别信文档里的旧结论
  ```bash
  ls -lh /workspace/ComfyUI/models/diffusion_models/   # H3 权重
  ls -lh /workspace/ComfyUI/models/checkpoints/ /workspace/ComfyUI/models/diffusers/  # T2I（空=无）
  ```
- **预防**：把「已装模型清单」写进 Pod 启动自检脚本，每次开机打印

### 7. ComfyUI 认证 401 / 密码未设置
- **现象**：API 请求返回 401/网页进不去/自动化脚本失败
- **根因**：ComfyUI-Login 插件，**密码文件不存在则一律 401**，首次 POST `/login` 即设置
- **修复**：
  - 启动脚本首件事：`curl -X POST http://127.0.0.1:8188/login -d "password=xxx"`
  - 密码存 `<ComfyUI>/login/PASSWORD`，持久化到网络卷
- **预防**：Pod 启动脚本自动配置登录

### 8. UI → API 格式转换三大坑 → 参数映射错/生成失败/时长不对
- **现象**：ComfyUI 网页能跑，API 调用失败/时长不对/参考图不生效
- **三大坑（实测）**：
  1. **时长参数**：改 `134 PrimitiveFloat`（秒，经公式换帧），非 `132` width/height（废值被连线接管）
  2. **进度条 `x/20` 是采样步数，与时长无关**——别据此判断剩余时间
  3. **参考式提示词是连线不是字符串**——`comfy_patch.py` 必须按连线注入
- **修复**：`comfy_ui2api.py` + `comfy_patch.py` 标准化转换，**参数映射实测吻合**
- **预防**：转换脚本单测/回归测试/版本锁定

### 8b. `podResume` 报「宿主机无空闲 GPU」→ 需 30 秒轮询重试
- **现象**：Pod 停机后 `podResume` 持续返回 `There are not enough free GPUs on the host machine`
- **根因**：Pod 绑定固定宿主机（`machineId`），该机 GPU 被占满时无法启动
- **修复**：**每 30 秒轮询 `podResume`**，宿主机腾出 GPU 即自动起来（实测第 9 次、约 4.5 分钟后成功）
- **预防**：把轮询做成脚本（`_validate/pod_resume_loop.sh`），别手动重试
- ⚠️ **别急着新建 Pod**：`podResume` 保留原 Pod 的**本地卷**（模型不重下）；新建 Pod 会换宿主机 → **重下 70GB+**

### 8c. `/tmp` 不随 Pod 重启保留 → `oi.json` 丢失致转换失败
- **现象**：`comfy_ui2api.py` 报 `FileNotFoundError: /tmp/oi.json`
- **根因**：`/tmp/oi.json`（ComfyUI object_info）存在 `/tmp`，**Pod 重启即清空**
- **修复**：重启后先重新拉一份：
  ```bash
  curl -s -b ck.txt http://127.0.0.1:8188/object_info -o /tmp/oi.json
  ```
- **预防**：Pod 启动脚本第一步就拉 `oi.json` + 登录 ComfyUI

### 9. 模型文件名不匹配 / LoraManager 空值
- **现象**：ComfyUI 启动报错 "Model not found"/LoraManager 报错空值
- **根因**：模板期望的文件名与实际下载文件名不一致/LoraManager 节点无默认值
- **修复**：
  - 下载后重命名为模板期望名（如 `fl2va.safetensors` / `ref2va.safetensors`）
  - LoraManager 节点设置默认 `none` 或移除未用节点
- **预防**：部署脚本校验文件名/节点配置

### 10. 显存 OOM / 模型加载失败 / 推理极慢
- **现象**：CUDA OOM / 模型加载卡死 / 单镜推理 >30分钟
- **根因**：
  - 4090 24GB 跑 H3(int8) + Qwen-Image(FP8) 需串行/分组加载
  - 并发过大/批次过大/未清理缓存
- **修复**：
  - 4090 上 H3 与出图模型**串行跑**（一个跑完再跑另一个）
  - 设置 `COMFYUI_MAX_VRAM=20GB` / 启用 `offload` / 定期清理缓存
  - 升级 5090 32GB+ / 或分 Pod 跑
- **预防**：监控显存/推理时间/自动降级

## 🟡 一般级

### 11. scp 传文件参数/路径/权限错
- **现象**：脚本/素材传不上/权限拒绝/路径不存在/文件损坏
- **修复**：
  - 统一用 `scp -r -P <port> -o StrictHostKeyChecking=no local/* root@<ip>:/workspace/`
  - 权限：`chmod +x *.sh *.py` / 目录 `chmod 755`
  - 路径：绝对路径/无中文/无空格/无特殊字符
- **预防**：部署脚本自动化传输/校验

### 12. 成片拉回本机慢/丢包/校验失败
- **现象**：`collect_shots.py` 超时/文件不全/MD5 不匹配
- **修复**：
  - `rsync -avz -e "ssh -p <port>" root@<ip>:/workspace/output/ _validate/shots_real/`
  - 完成后 `md5sum` 校验 / `ffprobe` 校验规格
- **预防**：拉回脚本集成校验/重试/断点续传

### 13. 本地环境差异 → ffmpeg/Python/依赖版本不一致
- **现象**：本机跑通，云上跑不通/反之/字幕烧录失败/音频编码失败
- **修复**：
  - **本地 ffmpeg 必须编译 `--enable-frei0r` + 预渲染素材**（代码规范）
  - Python 依赖 `requirements.txt` 锁版本 / `uv`/`poetry` 管理
  - 关键工具（ffmpeg/whisper.cpp/FunASR/ACE-Step）版本固定
- **预防**：Dockerfile/环境锁定/CI 校验

### 14. 无监控/无告警/无日志聚合 → 故障发现晚/排查难
- **现象**：任务卡死/报错/超支 发现时已晚/日志分散/无法追溯
- **修复**：
  - 关键指标监控：队列长度/显存/推理时长/成功率/成本/预算
  - 日志聚合：Loki/ELK/本地轮转/关键错误推送
  - 告警：队列空闲>30min/显存>90%/推理>阈值/成本>预算/预算>80%
- **预防**：Grafana/Prometheus/简单版用 cron + curl + 企微/钉钉/邮件

### 15. 无回滚/无灾备/单点故障
- **现象**：Pod 挂了/网络卷坏了/模型损坏/关键文件丢 → 全部重来
- **修复**：
  - 关键文件（模型/参考图/成片/脚本/配置）多地备份：本地 + Git LFS + 云盘
  - 部署脚本幂等/可重入/版本化
  - 关键节点快照/镜像版本化
- **预防**：灾备演练/季度恢复测试
