# 发布常见坑避坑指南

> **来源**：平台实战 + traffic-strategist + 合规.md + 短剧方法论§1.2/§5 + 政策文档
> **核心原则**：**合规前置、多平台同发、数据回填方法论、私域沉淀**

---

## 🔴 致命级

### 1. AI 生成标识缺失/不显著 → 限流/下架/封号
- **现象**：发布后流量极低/被判"未标识 AI"/申诉失败
- **根因**：平台强制要求（微短剧管理办法/抖音/快手/B站/视频号/小红书均有规定）
- **修复**：**三重标识**：
  - 视频内：首帧/末帧/角标任一处加"AI生成"，字号≥24px，对比度≥4.5:1，时长≥3s
  - 字幕：含"AI生成"字样
  - 文案：标题/简介/话题含 `#AI生成 #AI短剧 #AI创作`
- **预防**：发布清单强制勾选，build.py 可自动烧录水印

### 2. 版权/IP 未授权 → 侵权判赔/下架/封号/法律风险
- **现象**：用番茄/晋江/网文原文喂 AI 生成 → 版权方投诉/法院判赔 2万/账号封禁
- **根因**：**喂未授权小说给 AI 生成 = 侵权**（已有判赔案例，合规.md §三）
- **修复**：**必须走官方授权**：
  - 番茄 IP 库官方申请（个人可申请，1长5短/月）
  - 阅文/晋江/掌阅/漫画平台官方授权
  - 自有原创/公共领域
- **预防**：立项前 fact-checker 核查 IP 状态，producer 确认授权书

### 3. 肖像权/声音权未授权 → 侵权赔偿/下架
- **现象**：真人出镜/配音/声音克隆未签授权 → 被起诉/赔偿 500-1500元/人
- **根因**：肖像权/声音权属人身权，未经授权商用即侵权
- **修复**：
  - 真人出镜/配音：签署《肖像权授权书/声音授权书》
  - AI 生成人脸：不模仿特定真人/公众人物
  - 声音克隆：仅用授权音色/自有录制/商用授权 TTS 音色
- **预防**：合规核查清单强制项

### 4. 微短剧备案缺失 → 不得上线/平台拒收/监管罚款
- **现象**：发布被拦截/平台提示"缺少备案号"/广电查处
- **根因**：《微短剧发展管理办法》三类备案强制
- **修复**：上线前完成：
  - 剧本备案（广电/网信）
  - 拍摄备案（涉外/涉军/重大题材）
  - 发布备案（平台通常代办，但需提供材料）
- **预防**：项目启动时同步启动备案流程

### 5. 违规内容（政治/色情/暴力/赌博/医疗/金融/封建迷信） → 封号/罚款/刑责
- **现象**：发布即封禁/账号注销/法律追责
- **根因**：平台/监管零容忍红线
- **修复**：发布前自查清单（见合规核查清单.md）
- **预防**：敏感词库/画面自查/音频自查/三审制度

## 🟠 严重级

### 6. 单平台单号发布 → 流量上限低/抗风险弱/变现单一
- **现象**：一条视频只发抖音/只发一个号，流量跌则死
- **修复**：**多平台同发 + 多号矩阵**：
  - 主号（精品/品牌/沉淀粉丝）
  - 子号 3-5 个（测款/切片/花絮/垂类/不同人设）
  - 平台：抖音/快手/B站/视频号/小红书/西瓜/小程序
  - 差异化：标题/封面/标签/发布时间/人设微调
- **预防**：发布 SOP 自动化分发脚本

### 7. 标题/封面/标签随意 → 点击率低/推荐少/搜不到
- **现象**：完播率高但点击率<2%/搜索流量为0
- **修复**：
  - **标题**：核心关键词前置 + 情绪钩子 + 悬念/利益点 ≤30字
  - **封面**：1080×1920，高清/高对比度/含标题文字/主体压中轴/无水印/无低质感
  - **标签**：3-8个精准垂类标签 + 1-2个热门大标签（如 #AI短剧 #短剧推荐 #爽剧）
  - **SEO**：正文/评论区/合集布局长尾关键词
- **预防**：发布模板标准化

### 8. 发布时间随意 → 错过黄金流量窗口
- **现象**：深夜发布/工作时间发布/周末不发，自然流量<500
- **修复**：按平台黄金时段（见分发策略卡）：
  - 抖音：午休 12-13点 / 晚高峰 18-20点 / 深夜 22-24点
  - 快手：早 6-8点 / 午 11-13点 / 晚 17-19点 / 夜 21-23点
  - B站：周五/周六 19-21点（周末追番高峰）
  - 视频号：早 8-9点 / 晚 8-9点
  - 小红书：早 8-10点 / 晚 8-10点
- **预防**：定时发布/发布日历固化

### 9. 无引导互动/无私域沉淀 → 粉丝不增/复购为0/长尾为0
- **现象**：播放几万但掉粉/评论区死/私域为0/变现靠运气
- **修复**：
  - **视频内**：前3秒钩子/中间悬念/结尾引导"关注看后续/评论区投票/主页领资料"
  - **评论区**：置顶引导/回复每条/发福利/投票互动
  - **私域**：主页挂链接/粉丝群/企微/公众号/小店/小程序
  - **系列化**：固定更新日/专栏合集/追番提醒
- **预防**：运营 SOP 标准化

### 10. 数据不回填方法论 → 下一集重复错/选题靠猜/永远不懂用户
- **现象**：每集选题靠拍脑袋/完播率不稳/永远不知道为什么火/为什么扑
- **修复**：**发布后 7 日数据必须回填方法论**（短剧方法论§1.2/验收标准 L1#5）：
  - 完播率/3s/5s/完播/互动/转发/关注/搜索/画像
  - 对照选题假设/钩子/爽点/结尾/发布时间/标题封面
  - 更新《爆款题材调研-YYYY-MM.md》《短剧方法论》数字
- **预防**：复盘模板强制填写数据

## 🟡 一般级

### 11. 发布后不管/不回评/不维护 → 口碑差/算法判定低质
- **现象**：发完就跑，评论区骂声/提问无人回/算法判定"运营弃号"
- **修复**：发布后 24h 必守：回复每条评论/置顶优质/屏蔽违规/引导互动

### 12. 切片/二创/衍生内容零产出 → 单条内容价值未最大化
- **现象**：一条 60s 短剧只发一次，无切片/花絮/教程/OST/周边
- **修复**：一条成片 → 3-5 条切片(高光/反转/金句/花絮/教程) → 多平台二次分发

### 13. 付费/分账/商单流程不规范 → 漏收/纠纷/税务风险
- **现象**：分账不到账/商单未开票/税务合规/合同漏洞
- **修复**：
  - 分账：平台后台核对/月度对账/保留截图
  - 商单：合同先行/验收标准/付款节点/违约条款/发票合规
  - 税务：个体户/公司主体/发票开具/成本票入账

### 14. 跨平台同步发布时间冲突/版本不一
- **现象**：抖音发了快手才发/B站版本没标识/小红书引流违规
- **修复**：
  - 统一发布日历/版本管理
  - 平台差异化：标题/封面/标签/标识位置/引导话术
  - 小红书：不留微信/外链，用"主页看更多/粉丝群/小店"
