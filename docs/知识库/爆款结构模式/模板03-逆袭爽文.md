# 逆袭爽文结构模式模板

## 核心承诺

- **观众看的是什么**：对手的轻视或压迫当众落地，主角手里有对手看不见的底牌，奖励兑现或当众打脸，旁观者改口也算。
- **戏剧承诺公式（STY-01）**：当【被低估者/隐藏大佬】用【示弱/隐忍/看似妥协实则布局】追求【身份揭露/权力夺回/尊严捍卫】时，【对手的傲慢压迫+旁观者的偏见】迫使其付出【忍辱负重/暴露风险/被迫出手】；系列反复兑现【当众打脸/身份揭露/旁观者改口】，直到【终极对决/建立新秩序/不再需要隐藏】发生。

## 压力机制与冲突发动机

**压力来源（多源交互，STY-02）**：
1. **对手傲慢压迫**：当众做过的具体羞辱事（当面推回申请、群里带头举报、公开断言"不好看就别回来"）——参考 genre-cards/系统流.md 第16行、genre-cards/复仇打脸.md
2. **旁观者偏见**：集体嘲笑/看不起，形成社会压力场
3. **身份暴露代价**：隐藏身份一旦暴露可能引来更大麻烦（豪门恩怨/商战/暗杀）

**冲突发动机（reveal-reversal-payoff.md §4）**：
- 因为<隐藏身份/底牌>，原计划<对手按表面判断下注>失效，人物现在只能在<隐忍积累/选择性暴露/全盘托出>之间行动
- 对手学习型施压：失败后识别主角打法→改资源/规则/舆论→逼主角放弃旧优势

## 人物策略与信息权限

- **主角核心策略**：示弱诱敌、关键时刻暴露一手、用对手规则反杀对手
- **信息差设计**：
  - 观众+主角知道真实身份/实力
  - 对手/旁观者只看到表面（外卖员/保安/废婿）
  - 关键盟友可能半知半解（制造张力）
- **退出成本（story-craft.md §3.2）**：身份暴露=家族恩怨/商战升级/爱人危险，不能轻易坦白

## 观众回报与情绪落点

**回报双层（genre-cards/逆袭.md 第24-25行 + 复仇打脸卡）**：
1. **奖励兑现/打脸**：能看见的数（股份/地位/道歉/改口），旁观者集体改口、前辈站出来
2. **身份揭露**："没有我，你什么都不是"被当众证实，可核对的位置变化

**回报落点（story-craft.md §2）**：落在地位/权力上，必须是可核对的位置变化，仅有内心痛苦不够。

**情绪波形（方法论§3.1）**：压抑(被羞辱/被低估)→转折(露一手/反击)→释放(打脸/揭露)；大爽点分期兑付，不能第一集用完（方法论§4.2）。

## 标准场面颗粒

**必拍画面清单（genre-cards/逆袭.md 第28-29行）**：
- 对手当众做过的事、见证者分区、奖励的可见数值（屏显交给后期）
- 对手笑容僵住、有人默默删掉自己刚发的那条、围观者掏出手机
- 被推回又被抢着要回的文件/合同、对手接到的一通电话

**视觉锚点**：
- 身份道具（黑卡/印章/钥匙/戒指/文件）连续性锁
- 主角服装/气质变化：隐忍期vs暴露期（制作红线§6 造型一次锚定）
- 场景层级：从底层场景(外卖站/工地/旧宅)→高层场景(总裁办/豪宅/会所)

**后期分担项**：屏显数值(股份/资金/股价)、身份证件特写、新闻推送/热搜榜单

## 集尾钩子取向

**可选钩子类型（genre-cards/逆袭.md 第32-33行）**：
1. 新任务/新目标弹出且奖励更大
2. 离大目标还差一个具体的数
3. 对手换了更狠的手段（找更大靠山/针对性设局）
4. 刚到账的奖励/揭露的身份引来新的眼红者

**禁止钩子**：重复受辱—亮牌循环；身份揭示不改变任何人的行动空间。

**门槛集停法（episode-design.md §4.3）**：停在揭晓前一秒——身份即将完全暴露/终极对决前一招/关键筹码即将到手前一帧。

## 前中后期打法

**前期（第1-3集，genre-cards/逆袭.md 第36-37行）**：
- 第1集内：建立被低估现状 → 对手当众羞辱 → 主角露一手/反击 → 首次打脸
- 大目标具体可核对：夺回公司/报复渣男/保护亲人

**中期（第4-7集，genre-cards/逆袭.md 第38行）**：
- 对手学会了：换渠道、找更大靠山、针对主角规律设局
- 奖励/打脸越大，任务越难，主角在两个选择间纠结（道德成本变量）

**后期（第8-10集，genre-cards/逆袭.md 第39行）**：
- 隐藏身份/系统来历成为新问题
- 终极对决，结局气质由创作者决定

## 制作难点与规避

**资产量控制**：
- 身份道具/证件/屏显交给后期（生成画面不写可读文字，制作红线§7）
- 场景分级：底层场景复用率高，高层场景少而精
- 群体见证者分区：知情者/决策者/利益相关者/旁观者（genre-cards/家庭关系.md 第111-112行）

**连续性追踪**：
- 身份道具状态(被藏/被拿出/被验证/被认可)
- 对手阵营/手段/筹码变化
- 旁观者立场变化轨迹

**后期分担项**：屏显数值、证件特写、新闻/热搜、身份验证动画

## 禁止漂移清单

**来自题材卡（genre-cards/逆袭.md 第46-47行 + 复仇打脸卡）**：
- ❌ 不要重复受辱—亮牌循环
- ❌ 身份揭示不改变任何人的行动空间
- ❌ 奖励换成焦虑条款
- ❌ 删掉喜剧反应/第一次打脸拖到很多集后
- ❌ 对手降智/关键时刻犯傻（reveal-reversal-payoff.md §4 弱反转）

**方法论§13 对应**：
- ❌ 铺垫过长，前15秒没怪事
- ❌ 中段注水：同质反转重复
- ❌ 一集想讲两件事
- ❌ 爽点一次用完/没有等级感

## 快速套用检查表

- [ ] **主角3秒代入**：`[外卖冲锋衣/旧工牌/结疤的手] + [被当众羞辱/推回申请] + [淡定露一手/掏出黑卡/一句"合同用我名下公司"]`
- [ ] **前3秒钩子**：画面级羞辱/威胁（非台词），主角反应定义身份（镇定=高手）
- [ ] **单集只推进一件事**
- [ ] **反转频率**：15-20秒微反转，每集≥2爽点（打脸/揭露/改口/数值跳动）
- [ ] **结尾新危机**：更强对手/更大阴谋/身边人危险/时限倒计时
- [ ] **台词金句**："错一笔烧一命" / "合同用我名下公司" / "上次问这问题的人现在在哪"
- [ ] **可拍性红线**：单人情绪镜头为主，禁多角色同框/大场面
