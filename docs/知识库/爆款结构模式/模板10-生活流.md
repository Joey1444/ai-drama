# 生活流结构模式模板

## 核心承诺

- **观众看的是什么**：一个具体小目标被来客/误会/匮乏/照料义务打断。小事被实际完成、放弃或重新理解，关系留下轻微但可见变化。生活流的强度不来自更响的冲突，而来自私下发生的事带来真实余波。
- **戏剧承诺公式（STY-01）**：当【普通小人物】用【日常手艺/人情往来/固执坚持】追求【一个具体小目标/守住一种生活方式/照料好身边人】时，【来客打断/误会升级/匮乏加剧/照料义务冲突】迫使其付出【妥协/改变/放手/重新理解】；系列反复兑现【一顿饭做成/一个物件修好/一段关系缝合/一个誓言兑现】，直到【生活重回轨道/新的平衡建立/不再需要证明】发生。

## 压力机制与冲突发动机

**压力来源（多源交互，STY-02，genre-cards/生活流.md 第16-17行 + genre-and-hook-playbook.md §生活流）**：
1. **具体小目标被打断**：做顿饭/修个椅子/种棵菜/攒笔钱/陪孩子写作业 → 来客/误会/匮乏/照料义务介入
2. **私人义务与自我保护冲突**：经济/照料/名誉筹码可执行（genre-and-hook-playbook.md 第97-98行）
3. **环境节奏与留白**：日常物件/距离/手部选择/环境节奏——不是套用爽剧的密集大特写和公开翻盘

**冲突发动机（genre-and-hook-playbook.md 第100-106行）**：
- 互相照料/共同承受匮乏 → 让双方有牵挂和亏欠 → 私人排斥/伤害留下可携带证据 → 受影响者自我保护选择 → 证据进入有人能决定的公开场合 → 见证者各自获得新事实改变行动 → 退出/保护/作证真正改变权力
- 照料既证明爱也可以成为控制手段（genre-and-hook-playbook.md 第113-114行）

## 人物策略与信息权限

- **主角核心策略**：手部动作表达情绪/物件承载记忆/距离感知关系/环境节奏留白——不靠台词说、靠做出来
- **信息权限（genre-and-hook-playbook.md 第111-112行）**：
  - 群体反应按"能做什么"分区：知情者/能作决定的人/利益相关者/旁观者
  - 每组只在新事实改变其行动时反应，不能用一圈惊叹代替实际后果
- **退出成本**：放弃=失去手艺/断了关系/毁了誓言/辜负托付，不能轻易走

## 观众回报与情绪落点

**回报核心（genre-cards/生活流.md 第24-25行）**：
- **小事被实际完成/放弃/重新理解**：一顿饭端上桌/一个椅子坐稳了/一棵菜收成了/一笔钱用在了刀刃上
- **关系留下轻微但可见变化**：称呼变了/多递了一筷子/多留了一个座位/晚归多亮了一盏灯
- **真实余波**：不预设团圆/原谅/公开反击才是正确结局（genre-and-hook-playbook.md 第114行）

**回报落点**：落在生活/关系/物件上——具体的完成、具体的变化、具体的余波。

**情绪波形**：小目标启动(平静)→打断介入/冲突升级(微张力)→完成/妥协/重新理解(温暖释放)；不追求高潮迭起，追求真实感与共鸣。

## 标准场面颗粒

**必拍画面清单（genre-cards/生活流.md 第28-29行）**：
- 日常物件: 锅碗瓢盆/针线剪刀/农具种子/账本发票/作业试卷/药方处方
- 距离: 桌对桌/床对床/门槛内外/案板案下/筷子碰碗沿/手背擦汗
- 手部选择: 洗菜/切肉/穿针/拧螺丝/翻书页/签字/摸头/递筷子/倒茶
- 环境节奏: 晨光/炊烟/雨声/风扇声/锅铲声/翻书声/呼吸声/脚步声
- 留白: 吃饭不说话/走路不赶路/发呆看天/擦桌子擦出神

**视觉锚点（连续性锁）**：
- 核心物件状态: 生→熟/坏→修/种→收/欠→还/乱→序
- 空间领地: 谁的碗/谁的椅子/谁的床/谁的抽屉/谁的工位
- 称呼/动作微变: 从"喂"到"妈"/从递筷子到夹菜/从关门到留灯

**后期分担项**：极少——生活流以实拍/实物/实景为主，后期仅做色调统一/响度标准化/字幕

## 集尾钩子取向

**可选钩子类型（genre-cards/生活流.md 第32-33行）**：
1. 小目标即将完成/放弃/重新理解(悬念钩: 最后一道菜能不能上桌/椅子能不能坐稳)
2. 关系即将发生轻微变化(情绪钩: 称呼即将改变/座位即将多留/灯即将亮起)
3. 新的来客/匮乏/照料义务即将到来(悬念钩)
4. 环境节奏即将被打破(台风/停电/生病/搬家/拆迁)

**禁止钩子**：套用真人爽剧的密集大特写和公开翻盘，压扁生活质地（genre-cards/生活流.md 常见问题）。

**门槛集停法**：停在完成前一秒——最后一筷子即将夹起/最后一颗螺丝即将拧紧/最后一个字即将签下/门即将被推开前一帧。

## 前中后期打法

**前期（第1-3集，genre-cards/生活流.md 第36-37行）**：
- 建立日常节奏与核心小目标(做顿饭/修个物/种棵菜/攒笔钱)
- 来客/误会/匮乏/照料义务介入打断
- 首次微变化: 关系留下可见痕迹/物件完成度推进

**中期（第4-7集，genre-cards/生活流.md 第38行）**：
- 同类打断升级但形式变化: 来客变熟客/误会变默契/匮乏变共度/照料变双向
- 小目标分支: 主目标旁生出支线(顺手帮邻居/教会徒弟/记录手艺/传下规矩)
- 关系网密度增加: 邻里/亲戚/同事/路人形成微型社区

**后期（第8-10集，genre-cards/生活流.md 第39行）**：
- 小目标完成/放弃/重新理解
- 关系留下轻微可见变化成为新常态
- 生活重回节奏, 但已不同于开头
- 结局气质由创作者决定

## 制作难点与规避

**资产量控制**：
- 核心物件实物道具为主, 少后期(生活流最省钱题材)
- 场景高度复用: 厨房/院子/作坊/书房/菜地/小卖部/医院走廊
- 自然光/实景/实物/实操: 尽量少绿幕、少特效、少合成

**连续性追踪**：
- 物件状态/空间领地/称呼动作微变/环境节奏逐集锁定
- 关系网每个节点的微变化轨迹

**后期分担项**：仅色调统一/响度标准化/中文字幕/必要时间卡

## 禁止漂移清单

**来自题材卡（genre-cards/生活流.md 第46-47行）**：
- ❌ 套用真人爽剧的密集大特写和公开翻盘，压扁生活质地
- ❌ 把小目标变大目标/把微变化变大反转/把真实余波变爽点爆发
- ❌ 奢华/寒酸形容词堆叠代替物件细节和手部动作
- ❌ 用旁白替代可见的手部动作和物件状态
- ❌ 预设团圆/原谅/公开反击才是正确结局

**方法论§13 对应**：
- ❌ 铺垫过长，前15秒没怪事(生活流怪事=一个具体打断)
- ❌ 中段注水: 同质日常重复无微变化
- ❌ 结尾强行大团圆/大爆发

## 快速套用检查表

- [ ] **主角3秒代入**：`[锅铲/针线/账本/农具] + [来客敲门/停水停电/孩子生病/长辈催婚] + [手不停/火候不乱/节奏不乱/多留一碗]`
- [ ] **前3秒钩子**：画面级具体打断(敲门声/报警声/哭声/催款电话/暴雨声) + 手部动作不停
- [ ] **单集只推进一件事**：完成一道菜/修好一件物/搞定一个关系/攒成一笔钱
- [ ] **反转频率**：物件状态变化/手部动作微变/称呼距离微调/环境节奏切换，每集≥3处可感知变化
- [ ] **结尾新危机/新平衡**：新来客/新匮乏/新照料/新季节/新物件/新距离
- [ ] **台词标准**：极少台词/方言/俗语/停顿/沉默/环境音当台词，"吃饭了"比"我爱你"更有力
