# 豪门婚恋结构模式模板

## 核心承诺

- **观众看的是什么**：关系尚未被承认，监护/抚养/名分的硬期限持续逼近答案。名分或责任真的落地：签字、称呼、接送、监护归属改变。豪门婚恋的核心是"名分之争"——契约婚姻转真、隐婚转公开、破镜重圆有证据。
- **戏剧承诺公式（STY-01）**：当【契约妻/隐婚夫/被抛弃者】用【协议履行/隐忍守护/反向追逐】追求【名分落地/真心被看见/责任被承担】时，【豪门规则/家族压力/前任/私生子/继承权】迫使其付出【暴露身份/牺牲自由/对抗家族】；系列反复兑现【一纸文书签下/当众认亲/旁观者改口/对手吃瘪】，直到【名分正妻/孩子归属/家族接纳/建立新规则】发生。

## 压力机制与冲突发动机

**压力来源（多源交互，STY-02）**：
1. **豪门规则/家族压力**：监护权/继承权/联姻/家族声誉的硬期限（genre-cards/亲子隐秘.md 第16-17行：就学就医硬期限）
2. **对手的实质手段**：当众做过的事——泼酒、抢位、翻旧账、造谣、切断资源（genre-cards/复仇打脸.md）
3. **关系边界模糊**：私人义务与自我保护冲突，经济/照料/名誉筹码可执行（genre-and-hook-playbook.md §家庭与关系戏）
3. **证据归属与公开**：关键文件/录音/账目/亲子鉴定/结婚证——文字要清楚可读，只保留图形或留后期（genre-and-hook-playbook.md 第115-116行）

**冲突发动机**：互相照料/共同承受匮乏→私人排斥留下可携带证据→受影响者自我保护选择→证据进入公开场合→见证者各自获得新事实改变行动→退出/保护/作证/让路真正改变权力（genre-and-hook-playbook.md 第100-106行）。

## 人物策略与信息权限

- **主角核心策略**：协议履行中藏反击/隐忍守护中积累筹码/反向追逐让对方先动心
- **信息权限（genre-and-hook-playbook.md 第111-112行）**：
  - 群体反应按"能做什么"分区：知情者/能作决定的人/利益相关者/旁观者
  - 每组只在新事实改变其行动时反应，不能用一圈惊叹代替实际后果
- **退出成本**：离婚=孩子归对方/断绝经济来源/家族报复，不能轻易走

## 观众回报与情绪落点

**回报核心（genre-cards/亲子隐秘.md 第24-25行 + 豪门婚恋卡）**：
- **名分/责任真的落地**：签字、称呼、接送、监护归属改变
- **照料既证明爱也成控制手段**：保留双方实际手段和底线，不预设团圆/原谅/公开反击才是正确结局（genre-and-hook-playbook.md 第113-114行）
- **旁观者/决策者改变行动**：长辈认可/律师见证/媒体曝光/股东投票

**回报落点**：落在关系/名分/责任上——可核对的签字/称呼/接送/监护权变更。

**情绪波形**：私人义务冲突(压抑)→证据落地/公开场合(转折)→名分落地/责任承担(释放)；低谷不超过2-3集。

## 标准场面颗粒

**必拍画面清单（genre-cards/亲子隐秘.md 第28-29行）**：
- 签字与关系栏（户口本/结婚证/认亲书/遗嘱/亲子鉴定报告）
- 接送与等待（校门口/医院/机场/老宅大门）
- 可验证的检验流程（鉴定/公证/法庭/股东会）
- 孩子自己带来的物件/老人留下的信物/前任遗留的证据
- 长辈点头/律师见证/媒体闪光灯/股东举手

**视觉锚点（连续性锁）**：
- 关键文件/证物状态：被藏/被撕/被换/被签/被公证/被曝光
- 称呼变化：外人/夫人/太太/妈妈/女儿/继承人
- 空间权限：能进主卧/进书房/进族谱堂/进公司董事会

**后期分担项（制作红线§7）**：
- 画面内可读文字(证件/合同/鉴定报告/遗嘱/短信/转账记录)→后期贴
- 群体重复谴责/惊叹→后期合成

## 集尾钩子取向

**可选钩子类型**：
1. 关键文件即将签下/鉴定即将出结果/户口本即将翻开（悬念钩）
2. 对手造谣/绑架/断绝关系/切断经济来源已生效（情绪钩）
3. 孩子/老人/前任即将当众认亲/作证/揭露（信息钩）
4. 豪门规则/家族会议/股东大会即将投票裁决（情绪钩）

**禁止钩子**：群体重复谴责代替实际后果；孩子只负责卖萌撮合没有自己目标；血缘结果自动等于情感结果（genre-cards/亲子隐秘.md 禁止漂移）。

**门槛集停法**：停在揭晓前一秒——户口本翻到那页/鉴定报告封口即将拆/婚礼誓词即将说出/遗嘱关键条款即将宣读前一帧。

## 前中后期打法

**前期（第1-3集）**：
- 建立契约/隐婚/被抛弃现状 → 硬期限逼近(孩子入学/老人手术/继承权截止) → 首次证据落地/公开场合对峙
- 关系边界模糊：照料中藏筹码/协议中留后手

**中期（第4-7集）**：
- 证据进入公开场合 → 见证者分区改变行动（知情者/决策者/利益相关者/旁观者）
- 对手升级：造谣/绑架/断供/家族施压
- 主角在两个责任间选：孩子vs自由/名分vs真心/家族vs小家

**后期（第8-10集）**：
- 前期被忽略细节(一件物件/一句承诺/一个动作)成为决定性依据
- 名分落地/责任承担/建立新规则
- 结局气质由创作者决定

## 制作难点与规避

**资产量控制**：
- 关键文件/证物/证件交给后期（制作红线§7：画面内禁可读文字）
- 场景复用：豪宅/律所/法庭/医院/校门口/老宅/公司会议室
- 群体见证者分区合成，不扩张个人资产

**连续性追踪**：
- 文件状态/称呼/空间权限/筹码逐场锁定
- 群体反应分区：知情者/决策者/利益相关者/旁观者各自行动轨迹

**后期分担项**：证件/文件/鉴定报告/转账记录/聊天记录/监控画面

## 禁止漂移清单

- ❌ 孩子只负责卖萌撮合，没有自己的目标

- ❌ 关键文件文字不清楚可读，靠"大家看见了"建立在不可读画面上
