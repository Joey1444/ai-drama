## 一、通用约束（每一镜都适用）

| 项 | 规则 |
|---|---|
| 角色 | 每镜**最多 1 人**（追捕者只给局部/画外音，**永不露脸**） |
| 景别 | 特写 / 近景为主；**禁全景** |
| 外观 | 严格复述人物卡里的「外观连续性锁」，**不改措辞** |
| 光 | 画面里**只有符/屏幕可以发光**，其余压暗 |
| 台词 | 单镜 ≤2 句；按 **4.1 可发声字/秒**反算 |
| 画面内文字 | 全部**后期贴**，不让 H3 生成（**符文图形也算**，AI 必糊） |
| 参考图 | 出脸的镜才绑角色定妆图；手/物/环境镜一律文生 |

## 四、参考图策略（**本轮最关键的选择**）

本剧**没有静态出图平台**（方案 v2 的 A 档：零新平台）。所以定妆图**由 H3 自己出**：

| 步骤 | 做什么 |
|---|---|
| 1 | 先用 **H3 文生**出 **2 个定妆镜**（陈默 / 老墨各一，4s，正脸、中性光、闭嘴、看向镜头外） |
| 2 | 从产物里**抽一帧正脸闭嘴帧**当参考图（**别抽说话帧**——方法论 §7.2、§3-A5） |
| 3 | **M02 / M03 / M08** 三镜绑这张图（`用途：身份`），走 **full-reference** |
| 4 | 其余 **10 镜**（手/物/环境/背身）**一律文生**，不绑图 |

> 只让**真正出脸、且收尾脸在画内**的 3 镜绑参考图（producer 复核：此逻辑站得住）。
> 手/物/环境镜**没有脸可漂**，绑图只会把无关构图一起锁进来。

## 六、后期特效清单（ffmpeg，不依赖 H3）

| 镜 | 效果 |
|---|---|
| M01 | **叠字**「最后一个会画符的人，刚死了。」+ 降饱和 |
| M10 | **金色辉光**（核心奇观）——`split + gblur + blend=screen` **已实测可做**。⚠️ **粒子**见下方实测结论 |
| M11 | 门外声场的低频压缩 |
| M12 | **不做任何后期叠层**——浅纹全由 H3 出（见修订记录；ffmpeg 无特征点跟踪，叠在移动的手上会漂） |
| M13 | 门外声场的低频压缩（**比 M11 更重**）+ 收尾**黑屏由后期做** |
| 全集 | 冷调色（青灰）+ 轻噪点 |

> ❌ **砍掉的一项**：① 手背**清晰符纹**（producer：ffmpeg 无特征点跟踪，会漂）
>
> 🔬 **粒子：已在本机实测（2026-10-09，证据在 `_validate/fx/`）**
>
> | 做法 | 结果 |
> |---|---|
> | 胶片噪点 / 颗粒 | ✅ `noise` 可用 |
> | 色散 RGB 偏移 | ✅ `chromashift` 可用 |
> | 辉光 bloom | ✅ `split + gblur + blend=screen` 可用 |
> | 「粒子」（离散上浮火星） | ❌ `noise` 只出**均匀颗粒**、`geq` 只出**竖条纹**、`frei0r_src=particles` 报 `Could not find module 'particles'` |
>
> **原因**：本机 ffmpeg **编译带了 `--enable-frei0r`，但没随包带 frei0r 插件 DLL**。
> **三条出路**：① **补一个 frei0r 插件包（约 2MB，不是新平台）** → `frei0r_src=particles` 立即可用 ② 用预渲染的粒子素材 overlay ③ 砍掉粒子，只留辉光
