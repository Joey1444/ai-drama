## 0. 一句话

**最后一个会手绘符的人死了。临死前，他把笔塞进了一个送外卖的手里——然后所有人都开始找这个送外卖的。**

---

## 1. 世界观（修订版 · 已修补 5 个逻辑洞）

**现代都市，法师靠符。市面流通的是工厂印的「模板符」——便宜、合法、够用。**

| | 模板符（机器印） | 手绘符 |
|---|---|---|
| 能力 | 只能承载**固定术式**（"火球术·标准型"） | **看懂对手路数，当场画一张克制的符** |
| 地位 | **协会认证、合法** | **被判"非标品·非法"** |
| 价格 | 便宜 | 贵、慢 |

**修订的三个关键点（补住了原来的逻辑洞）**：

1. **不是自然竞争，是政治清洗**——协会要**垄断最强武力、清除不受控的变数**，所以立法把手绘判为非法。（❌ 不用"资本逐利"解释——隐秘行业市场太小，资本没动机）
2. **主角不是唯一，是最后一个"不在协会手里"的自由手绘者**——协会**自己手里养着手绘者**，只是不告诉你。（❌ 原来"全世界只剩一个"解释不通：任何组织都会偷偷留一张底牌）
3. **手艺失传不是因为无人知晓，是因为没人愿意学**——练十年，不赚钱、不合法、还苦。

**"隐秘行业"的补法**：法师是小众行当，**普通人不知道**——但主角开场就是个**普通人**，他是**被卷进来的**。这样"规则就在身边，而你一无所知"的爽感还在。

## 2. 主角

**陈默，24 岁，送外卖的。**

第 1 集，他送单到一条巷子，撞见一个浑身是血的老头。老头把一支**毛笔**塞进他手里，说：**「别画错。」** 然后死了。

**从此他背着**：老头的仇、老头的追杀者、和一支他自己不会用的笔。

> ✅ 主角开场是**普通人**（不是传承者自述），代入感与 3 秒钩子都拉满
> ✅ 天然带一条"**速成求生**"成长线

---

## 3. 戏剧引擎（judge 说原来的装反了，这是修正版）

❌ 旧：各方追他（**猎杀型，主角被动，爽感越追越瘪**）
✅ 新：**手绘符是稀缺战略资源——他越强越值钱，越值钱越危险**

他每学会一张符，就多一分活命的本钱，也多一分被盯上的理由。**矛盾自己会长大。**

## 4. 10 集脊梁（单主线 + 一次大反转）

| 集 | 节拍 |
|---|---|
| **1** | 顶包——老头塞笔、死在他面前 |
| **2** | **模板符失灵**——他亲眼看见所有印刷符烧成灰，只有他手里那支笔还在 |
| **3** | 各方上线追他；他第一次照着老头的残页**画出一张符** |
| **4** | 被协会**招安**（给你身份、给你合法，只要你交出笔）→ 他拒绝 |
| **5** | 第一次靠手绘**反杀**——他看懂了对手的术式，当场画了一张克制的 |
| **6** | 他查到老头不是"最后一个传人"，是**被清洗的第一批**之一 |
| **7** | 协会内部有人偷偷帮他——**那个人也会手绘** |
| **8** | 他发现自己画的符，笔迹和老头的**一模一样**（他从没学过） |
| **9** | 追杀升级；他必须选：交出笔活命，还是画完老头没画完的那张 |
| **10** | **反转**：协会会长**自己就是手绘者**。他清洗同行，是为了**垄断"唯一"**。 |

> **10 集的大反转 = 追杀者就是同类。** 把"逃命"变成"宣战"，直接留给第二季。

## 5. 视觉符语言（judge 点名：**必须 3 集内建立**）

否则观众**看不懂符在干嘛**，剪在一起就是乱码。

| 类型 | 颜色 | 视觉特征 |
|---|---|---|
| 攻 | **红** | 笔画锐利、外扩 |
| 守 | **蓝** | 笔画闭合、成环 |
| 咒／禁 | **黑** | 笔画向内收、边缘碳化 |
| **手绘专属** | **金** | 模板符**永远印不出金色**——这是全剧最重要的视觉标识 |

**金色 = 手绘的签名。** 观众只要看到金火，就知道"这是他画的"。

## 6. 拍摄手法（每个都对应 H3 的硬限制）

| 场景 | H3 拍法 |
|---|---|
| 斗法 | **正反打**，且**不拍脸**——拍**对手的手 / 符 / 瞳孔里的反光**（避掉 H3 跨镜人脸一致性这个弱项，同时更压迫） |
| 打斗 | **招式特写 + 结果**：画笔的手 → 符燃 → 切对手后退的定格 |
| 符阵 | **脚下巨型符阵逐圈亮起**，人只占画面一个小点（尺度对比 = 奇观） |
| 大场面 | **POV 主观**：镜头就是他的眼睛，画面里**只有景没有人** |
| 环境异变 | 全城灯灭，**只剩他手里那点金光** |
| 特效震撼 | **后期叠光效 + 声压**（ffmpeg，不依赖 H3） |
