# 《符》· 10 集分集大纲（含钩子表 + 可拍性预演）

> 10 集试水 ｜ 2026-10-09
> 每集 60 秒。**钩子在 0–3 秒，反转在最后 5 秒。**
> 最后一列 = 可拍性预演：每个关键镜头都对着 H3 红线过一遍。

---

## 铁律（写每一集都要守）

1. **0–3 秒必须自成一个钩子**——不是"这集要讲什么"，是"这一秒发生了什么"
2. **结尾必须停在反转上**——不准平收
3. **不许解释世界观**——只给画面，让观众自己拼
4. **每集只推进一件事**

---

## E1 · 顶包

| | |
|---|---|
| **开场钩子（0–3s）** | 血手把毛笔塞进他手心（特写）→「**别画错。**」→ 黄符悬空自燃，**火是金色** |
| **推进** | 陈默送外卖拐进老巷，撞见浑身是血的老头；老头死；他手里多了支笔。他以为是恶作剧 |
| **结尾反转** | 他回到电动车旁——**外卖箱内壁烧出了一个符的形状**，而他手里那张"废纸"已经没了 |
| **关键镜头** | 血手特写 / 金色自燃 / 箱内焦痕 |
| **可拍性** | ✅ 全特写，单人 |

## E2 · 符，全死了

| | |
|---|---|
| **开场钩子（0–3s）** | 符店橱窗，**几百张印刷符同时自燃**，一串接一串 |
| **推进** | 全城的模板符在几个小时里陆续烧毁。他成了**唯一手里还有"活的符"的人** |
| **结尾反转** | 他摊开手——**那支笔自己在动** |
| **关键镜头** | 橱窗自燃链 / 他的手 + 自动写的笔 |
| **可拍性** | ✅ 单人 + 橱窗；自燃用后期叠火 |

## E3 · 第一张符

| | |
|---|---|
| **开场钩子（0–3s）** | 一只手的特写，把一张**灰色**的符按在墙上——**符没亮** |

| **关键镜头** | 画符三件套（手/纸/笔尖）/ 失败的灰符 |
| **可拍性** | ✅ 特写为主 |

## E4 · 招安

| | |
|---|---|
| **开场钩子（0–3s）** | 一只手推过来一张卡：「**加入协会，这支笔归你。**」 |
| **推进** | 条件、威胁、诱惑（正反打，**不拍脸**——拍对方的手、袖口、戒面） |
| **结尾反转** | 他拒绝后，对方说：「**那支笔，是我师父的。**」 |
| **关键镜头** | 卡特写 / 对方的手 / 陈默的手攥紧 |
| **可拍性** | ✅ 正反打不拍脸，每镜一人 |

## 全剧可拍性汇总

| 检查项 | 结果 |
|---|---|
| 多角色同框 | **0 次**（一律正反打） |
| 群戏 / 大场面 | **0 次**（奇观用尺度对比 + 局部暗示） |
| 复杂连续打斗 | **0 次**（招式特写 + 结果） |
| 单镜台词 >2 句 | 无（写剧本时逐镜核） |
| 画面内可读文字 | 仅"老照片背面的字"，**后期贴** |
| 角色数 | 4 人（≤2–3 人同场，且不同框） |

**结论**：10 集全部落在 H3 红线内。
