# 《符》· 视觉设定

> 10 集试水版 ｜ 2026-10-09 ｜ 用于：跨镜一致性 + H3 提示词 + 后期调色

---

## 一、符的颜色体系（**必须 3 集内建立**）

审判官点名：**H3 真正的杀手不是拍不出，是观众看不懂符在干嘛。** 所以颜色是硬约定。

| 类型 | 颜色 | 视觉特征 | 观众该读到 |
|---|---|---|---|
| 攻 | **红** | 笔画锐利、向外扩 | "这是打人的" |
| 守 | **蓝** | 笔画闭合、成环 | "这是挡的" |
| 咒 / 禁 | **黑** | 笔画向内收、边缘碳化 | "这是害人的" |
| **手绘专属** | **金** | 笔画有毛边、墨会**呼吸** | **"这是他画的"** |

> **金色 = 手绘的签名。** 模板符**永远印不出金色**——这是全剧最重要的视觉标识，也是观众区分主角的唯一线索。

**建立方式**：E1 让金色出现一次（老墨的符），E2 让主角画出**灰色**的失败符，E3 才第一次画出金色。**三集完成一次"颜色的获得"，观众就记住了。**

## 二、整体色调

**冷底 + 一点金。**

| 场景 | 色调 | 说明 |
|---|---|---|
| 老巷 / 符店 | 青灰 + 昏黄灯 | 主角的生活区，低饱和 |
| 协会大楼 | 冷白 + 金属灰 | 干净到没有温度 |
| 斗法现场 | 压暗，光源**只来自符** | 红/蓝/金成为画面唯一亮色 |
| 全城灯灭 | 纯黑 + 一点金 | **E5 的奇观镜头** |

**规则**：**画面里只有符可以发光。** 所有其他光源都被压。这样"符一亮，观众就知道要看哪里"。

## 三、镜头语言（对应 H3 硬限制）

| 目的 | 拍法 | 为什么 |
|---|---|---|
| 对峙 | **正反打，但不拍脸**——拍**对手的手、符、瞳孔里的反光** | 避掉 H3 跨镜人脸一致性这个弱项，且更压迫 |
| 斗法 | **招式特写 + 结果**：画符的手 → 符燃 → 切对手后退的定格 | 不拍"怎么打的" |
| 画符 | **手部 + 纸 + 笔尖**三件套特写 | H3 最强的地方 |
| 奇观 | **尺度对比**：脚下巨型符阵逐圈亮起，人只占一个小点 | 不拍全景也有奇观 |
| 大场面 | **POV 主观**：镜头就是他的眼睛，画面里只有景没有人 | 完美绕过"禁止多人" |
| 失败 | 符画到一半**碳化、卷边、烧穿纸** | 让"画错"看得见 |

## 四、关键道具（跨集连续性）

| 道具 | 外观连续性锁 | 作用 |
|---|---|---|
| **那支笔** | `一支旧狼毫毛笔，笔杆深褐发亮，笔头偏硬，杆身有一道浅裂纹` | 全剧核心物，**永远在他身上** |
| 老墨的残页 | `半张泛黄符纸，边缘焦黑，画了一半的金色符文` | E1 遗物，E9 要画完的那张 |
| 陈默的外卖箱 | `黑色方形外卖箱，贴纸翘边` | 开场身份标识，E3 后弃用 |

## 五、后期特效清单（ffmpeg，不依赖 H3）

奇观的"分量"有一半来自这里：

| 效果 | 用途 |
|---|---|
| **光晕 / 辉光** | 符燃烧时外发光 |
| **色散（RGB 偏移）** | 法术冲击瞬间 |
| **粒子** | 金色火星上浮 |
| **冲击帧（白闪 1 帧）** | 命中瞬间 |
| **扫描线 / 噪点** | 回忆、失控段落 |
| **低频轰鸣 + 突然静音** | **声音是奇观的另一半** |
