## 0. 结论：就这一条主线

**先用 Claude Code + MiniMax H3 跑通最小闭环（只做漫剧/图文解说，零新平台）→ 跑通后把 H3 搬到 RunPod 自跑降本 ~85% → 要上真人风时再加 1 个云出图平台锁脸。** 先跑通再加积木。

**凭什么同时满足三个验收**：**精简**=只 2 个外部平台（Claude Code + H3/RunPod），剪辑/字幕在本机 $0；**质量**=H3 原生对白+本机剪辑在漫剧/解说上就是天花板（环3/环5 判这类最易全自动）；**成本**=云 API 单集 $7.35 三档最低，搬 RunPod 后 $0.7–1.2。

**三档预算速览（单集 60s / 10 镜 / 1.5× 重抽）**

| 档位 | 单集成本 | 配置 | 换来什么 |
|---|---|---|---|
| **省钱档** | **$0.5–1.5（¥4–11）** | H3 **自跑 RunPod** 768P + 自锚定 | 画质中；一致性最弱；需自搭 |

## 1. 全链路总览（生成上云、编排剪辑在本机）

```
① 剧本/分镜  Drama-Skills(本机) +★人工把关
② 定妆图     云 T2I: Seedream / Qwen-Image【§3-B1, 可选】
③ 图生视频   MiniMax H3(云API/RunPod, 带原生对白)
④ 配音/BGM   H3 原生对白 + 云 BGM(§3-B2)
⑤ 口型       漫剧/解说可省; 真人特写才需(§3-B3)
⑥ 剪辑/字幕/导出 ffmpeg + whisper.cpp/FunASR(本机 CPU, $0)
⑦ 分发       social-auto-upload / Postiz +★人工登录
```

**一句话**：**生成类全在云/RunPod；编排、剪辑、字幕、导出全在本机 CPU。** 本机 780M 只跑 ffmpeg，不承担 AI 生成（与"无 CUDA"自洽）。**单段视频上限 4–15s**，长戏要拼接（§6）。

## 2. 最简链路：Claude Code + MiniMax H3（先跑这条）

`剧本+分镜 → 逐镜 T2V/R2V 带原生对白 → 拿回带声音片段 → ffmpeg 拼接+字幕+导出`。
**H3 两种跑法，务必分清（费用差 85% 的关键）：**

| 跑法 | 是什么 | 单集成本 | 前提 |
|---|---|---|---|
| **A. MiniMax 云 API** | 官方按秒付费，免部署 | **$7.35**（768P，1.5×） | 直接用 |
| **B. RunPod 自托管** | 社区 ComfyUI 模板（你给的 `7m9burperg`） | **$0.7–1.2** | 建 80G 储物柜、挂载、跑通 ComfyUI |

> ⚠️ 原方案把两者混标成"云 API"——**归属要写对：自托管 ≠ 云 API**，费用差 ~85%。

### H3"吸收"了哪一步、吸收不了哪几步（关键修正）

原方案写"H3 吸收掉配音+口型"——**只对一半**。支撑文件 `3-关键帧出图与图生视频.md` §9.6 反证："**原生音轨 ≠ 口型准确**"。

| ✅ H3 真正吸收的 | ❌ H3 吸收不了的（"配音"真正难的部分） |
|---|---|
| **"音频与画面同步生成"这一件事**（带对白的音轨随画面一起出） | ① 照剧本**逐字念**台词（无证据）② **音色克隆**（无证据；环4 从不把 H3 当 TTS）③ **情绪表演/停顿**（环4 §4.1"声音债"）④ **多角色谁说什么**（靠提示词硬写+人工核）⑤ **跨镜音色一致**（逐镜独立生成会漂）⑥ **BGM/音效**（H3 只提"对话"，**原方案漏了这行**） |

**结论**：H3 省掉的是"配音"里**容易的那半**（声音与画面同步生成）；台词准不准、口型对不对、有没有 BGM，**仍要人工核对 + 另配**。口型在漫剧/解说可省（观众容忍度高），真人特写不行（§3-B3）。

### 唯一缺口：H3 不生成静态图（无 T2I）
1. **纯 T2V**：直接文生视频 → 每镜长相随机，只适合图文解说；2. **自锚定**：抽一帧当后续镜头 R2V 参考 → 不引平台、一致性中等，**别盲抽说话帧**（§3-A5）；3. **外接出图**：接云 T2I（Seedream/Qwen-Image）走 I2V → **+1 平台**、一致性最好（=§3-B1）。

## 3. 质量补强：按"加不加新平台"分三档

**A 档：零新平台（Claude Code + H3 就能做）**（每条无新平台）：
A1 台词按 **4.1 可发声字/秒** 反算写死再喂 H3（治台词时长错位）｜A2 H3 出片**必过** whisper.cpp/FunASR 转写→字幕→**人工校对**｜A3 提示词用 **Drama-Skills 六段式 + 显式"说话人A说…；B 闭嘴"绑定**（治口型落错脸）｜A4 喂**固定参考音频**做音色锚（H3 支持 ≤3）｜A5 自锚定**不盲抽说话帧**，人工挑正脸/闭嘴帧｜A6 长镜首尾帧拼接 + **xfade 转场**，人工查接缝与卡点｜A7 多尺寸走**裁剪 + 人脸追踪**（clippyme 本机 CPU）｜A8 分发前加 **AI 生成标识**｜A9 保留 **"确认后生产"闸门**（Drama-Skills 原生，制止无人值守烧钱）。

| **B 档：加 1 个平台** | 解决什么 | **新平台** |
|---|---|---|
| B1 接云 T2I 出定妆图，H3 走 I2V | §2 唯一硬缺口（无 T2I）、跨镜脸/服装漂移 | **有**：Seedream 4.0（或 Qwen-Image，二选一） |
| B2 BGM/音效改走云 | §2 **净漏项**（H3 只出对白） | **有**：MiniMax music-2.6 或 ElevenLabs SFX |
| B3 口型兜底（**仅真人特写**） | "原生音轨 ≠ 口型准确" | **有**：Sync Labs（$2.4/分钟）/ Kling Lip Sync |

| **C 档：加 ≥2 平台（真人风才需要）** | 解决什么 | **新平台** |
|---|---|---|
| C1 RunPod 训**角色 LoRA** | 系列级脸一致（4-8h/角色，多角色同框仍不保） | **有**：RunPod（既有资源） |
| C2 漫剧口型走 **Hedra** | 漫剧口型唯一靠谱云端 | **有**：Hedra（6 credits/秒） |

**天花板**：零增平台（A 档全开）→ **漫剧/图文解说**；**真人风在"少平台"内不达标**（卡点是口型）→ 加云口型（B3）或放弃。
**最少必要增补**：① 先零平台跑漫剧/解说；② 要真人/治换脸，**加且只加 1 个云 T2I（Seedream）**把 T2V 换 I2V；③ **BGM/音效必须补**（B2；可先试本机 ACE-Step，装不上上云）；④ 真人口型当**付费兜底**。**最多 +2 平台即"少平台"的顶。**

## 6. 卡点 + 必须人工的环节

**卡点一：跨镜角色一致性**。模型逐镜独立生成、**无跨镜记忆**，无法 100% 消除漂移。**多角色同框最脆弱**（S2V-01 仅单主体、Vidu Q3 多图也互相污染）。稳定范围约 **6-12 场景**，更长要"每 6 镜一批"+ 人工抽检重跑。

**卡点二：表演层"能出但不能全自动"**。① **口型**：开源方案嘴部仅 256×256 → **特写糊脸**；主流模型只训真人脸 → **漫剧角色套上会扭曲（本环最大空白）**；全需 NVIDIA GPU。② **TTS 情绪**：音色能克隆，"犹豫/克制"演不出来（**声音债**）；跨集音色有漂移。③ **音画时长**：中文约 **4.1 可发声字/秒**，改一句台词可能重配+重剪。**共性 = 量产容易、精修靠人**：机器做 80%，剩 20% 必须人工。

**必须人工的环节**：1.参考图/定妆图筛选 2.漂移帧抽检→重跑 3.台词时长 vs 镜长 4.说话人标注校对 5.TTS 情绪抽卡 6.分镜节奏/剪辑感微调 7.中文字幕断句 8.国内平台登录态/验证码 9.AI 生成内容显式标识（2026 合规必加）10.肖像权/声音权授权（¥500-1500/张脸）。

## 7. 硬约束（别踩）

- **许可（对"赚钱"最致命）**：CC BY-NC-SA = **禁商用**（huobao-drama、BigBanana）；AGPL-3.0 商用衍生需评估（OpenMontage、ArcReel）；waoowaoo = **Elastic License 2.0（非 OSI 开源）**；**Wav2Lip 非商用**。许可不清 = 法务风险。
- **接口/格式**：分镜 JSON 无事实标准（换工具要重映射）；`pyJianYingDraft` 批量导出**只支持剪映 ≤6**。
- **算力墙**：本机 780M 无 CUDA → **ComfyUI/MuseTalk/GPT-SoVITS 等开源生成模型一台都跑不了**，只能 RunPod 或云 API。ACE-Step 1.5 是唯一例外候选（附录 B）。
- **时长/规格**：视频单段 ≤15s、配音单句常 8-10s → 不同步；多尺寸无无损全自动（重生成 或 裁剪丢内容）。

## 8. 停止信号（什么情况下这路走不通）

| 可观测信号 | 判定 |
|---|---|
| ① 跨镜漂移率长期 **>30% 且重跑不收敛**；或人工时长期 >3h/集 | → 降级"半自动+人工精修"；"无人值守量产"不成立 |
| ② 单镜成本 × 重抽使**一集 > 数百元**且质量仍不达标 | 该预算下"全自动量产"不成立 |
| ③ ACE-Step **ROCm 装不上** 且 **CPU 生成 1 首 >30 分钟** | 本机音频路径不可行 → 音频上云 |
| ④ 一站式项目**装不起来**或**许可不可商用** | "最省事"证伪 → 退回积木路径 |
| ⑤ 国内平台 **AI 风控/限流/封号**，或 AI 内容**拿不到流量/收益** | 分发/商业闭环证伪（**市场问题，换工具救不了**） |
| ⑥ 逐镜"AI 感"致**判非原创/降权** | 真人风"上不了台面" → 转漫剧/解说 |

> **原则：先跑最小闭环（§5 第 5 条），用真实产出对照上表；任一信号出现即停手重估"目标+约束"，别加码。**
