## 三、对本项目的含义

1. **「图文解说」路线在抖音被排除** → 若目标平台是抖音，形态必须走**仿真人漫剧或 2D/3D 漫剧**（难度更高：真人风一致性 + 口型）。
2. **题材由平台反推**：抖音征集的是**男频玄幻向**（都市高武/玄幻/西游/洪荒），与我此前推荐的「都市逆袭」不完全一致。
3. **多数激励要的不是"作品"而是"剧本 + 系列"** → 与制作人提的「系列化/IP 沉淀」是同一件事。
4. **本节全部结论有保质期**，正式投入前必须重查当日政策。

## 四、教训（流程）

派调研 agent 时，我把范围写成「全平台政策全景」——**这是个市场调研的无底洞，不是当前目标**。用户的当前目标是**跑通最小闭环、做出第一个成片**，平台政策属于下游。

**下次**：调研 agent 的范围必须钉在当前里程碑上（"帮我确认 X 能不能做 Y"），而不是开放式全景。
