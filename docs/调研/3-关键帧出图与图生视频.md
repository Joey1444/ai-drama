# 第 3 环：关键帧出图 + 图生视频

> 调研日期：2026-10-09 ｜ 所有星数/热度均为当日现查（GitHub API / 官方页），抓不到写"未查到"，不编造。
> 服务对象前提：零编程（会让 Claude Code 代写）、本机 AMD 780M 核显无 CUDA、Windows 11、云可用 RunPod + MiniMax 付费。
> 本环 = 分镜脚本 → **定妆图/场景图（文生图）** → **动态片段（图生视频/文生视频）**。

---

## 0. 一句话结论（先给总控）

本环**唯一真正卡死的环节是"角色一致性"**（跨镜头脸/造型漂移），没有任何工具做到 100% 全自动，必须人工抽检+重抽。相对地，**文生图定妆/场景已接近全自动，图生视频靠云 API（MiniMax H3 等）也无需本地算力**。对"零编程 + 无 CUDA + 愿意付费"的用户，**最省心路径 = 整合型平台（waoowaoo / LocalMiniDrama）当总控 + 云文生图（Seedream/Qwen-Image）出定妆图 + MiniMax H3 做图生视频**；纯开源模型（ComfyUI/Wan/HunyuanVideo）全部需要 CUDA，只能扔 RunPod，对零基础不划算。

---

## 1. MiniMax H3 在本环的准确位置（重点）

**结论：H3 落在"图生视频/文生视频"这一步（动态片段），不负责定妆图。定妆图要另配文生图模型。**

| 项 | 事实 | 来源 |
|---|---|---|
| 模型名 | `MiniMax-H3`（= 海螺 Hailuo 系列第三代）与 `MiniMax-H3-Max`（与 fal.ai 合作，主打高速，仅 480P/768P） | [platform.minimax.io 视频生成文档](https://platform.minimax.io/docs/guides/video-generation)（抓取 2026-10-09） |
| 是否支持图生视频 I2V | ✅ **支持**（H3 与 H3 Max 均支持） | 同上 |
| 是否支持角色/风格/动作参考 | ✅ Reference Generation（主体/风格/动作参考）；参考图 ≤9 张、参考视频 ≤3、参考音频 ≤3 | 同上 |
| 首尾帧控制 | ✅ 支持首帧图 + 末帧图（0–2 张，控制起止画面） | 同上 |
| 文生视频 | ✅ 支持（T2V） | 同上 |
| 音频 | 原生同步音轨（"音频 支持"） | [ofox.ai H3 页](https://ofox.ai/zh/models/minimax/hailuo-3)（抓取 2026-10-09） |
| 时长/分辨率 | 4–15s（整数秒）；768P / 2K（H3）；480P/768P（H3 Max） | 同上 |
| 价格 | **768P $0.08/秒；2K $0.13/秒**（按生成秒数计费，无月费） | [ofox.ai H3 页](https://ofox.ai/zh/models/minimax/hailuo-3)（抓取 2026-10-09） |
| 接入方式 | 异步 API：`/v2/video_generation` 建任务 → `/v2/query/video_generation/{task_id}` 轮询 → 下载 `content.url`；亦走 OpenAI 兼容 `/v1/videos` | 官方文档 + ofox（抓取 2026-10-09） |
| 云端 | ✅ 纯云 API，**不需要本地 CUDA** —— 完美匹配用户机器 | 同上 |

**在本环的定位图示：**
```
分镜 →[文生图: Seedream4.0 / Qwen-Image / FLUX / GPT Image]→ 定妆图·场景图(关键帧)
                                                              │
              ┌───────────────────────────────────────────────┤
              ▼                                               ▼
   [MiniMax H3: I2V / 首尾帧]  ──────────────→  动态片段(4–15s, 带音轨)
    或 [可灵3.0 Omni / Seedance2.0 / Vidu / Runway]（替代/互补）
```
- **能做什么**：把定妆图/场景图变成会动的镜头；用参考图/首尾帧维持角色与运动；一次最长 15s，带原生音频。
- **不能做什么**：不产定妆图（要另配文生图）；不自动保证跨镜一致（要靠参考图 + 人工抽检）；单段 ≤15s，长镜头要拼接。
- **替代/互补**：可灵 3.0 Omni（多镜头一次成、4K）、Seedance 2.0（身份锁定）、Vidu（角色一致强）、Runway（电影级）。开源替代 Wan2.1/HunyuanVideo/LTX-Video（需 CUDA）。**统一入口**可用 `video-generator-client`（已直接封装 MiniMax H3）。

## 8. 四类短剧在本环的难度差异

| 类型 | 文生图难度 | 图生视频难度 | 一致性卡点 | 本环成熟度 | 推荐组合 |
|---|---|---|---|---|---|
| **1 AI 真人风** | 高（写实脸易崩、手指/五官） | **最高**（写实动态、口型、表情） | 跨镜换脸最严重；参考图需 ≥1024×1024，一次最多稳 6 镜 | 难但可做 | Seedream 定妆 → 可灵 3.0 Omni / Runway Gen-4.5 出片 |
| **2 AI 动画/漫剧（二次元/漫画）** | 中（风格化易过） | **中**（动作幅度可夸张、容错高） | 风格化天然掩盖漂移 → **最容易全自动** | **最成熟** | waoowaoo / novella / LocalMiniDrama 直接一站；Seedream/即梦风格图 |
| **3 图文解说（图+旁白+字幕）** | 中（只要有图） | **最低**（几乎不需要真视频，动效/运镜即可） | 基本无 | **最容易全自动** | 文生图 + TTS(HunyuanVideo-Avatar 数字人) + 字幕；中文图用 Qwen-Image |
| **4 混合（真人素材+AI 特效/生成）** | 中 | 高（要抠像/合成/光照匹配） | 真人素材与 AI 生成的光影/质感对齐难 | 中，需人工合成 | Wan-Alpha（Alpha 通道）+ 分层合成（Qwen-Image-Layered）+ 剪辑 |

**结论**：对新手，**"漫剧/图文解说"最容易全自动跑通；"真人风"最难、最吃人工**；"混合"介于两者之间但要合成功夫。

## 9. 本环的"卡点"——哪里必须人工介入（不可全自动）

1. **角色跨镜一致性（最大卡点）**：模型逐镜独立生成、无跨镜"记忆"，必然漂移。缓解=3–5 张同角色参考图（≥1024×1024，正面/3/4/侧）+ 锚定首镜 + 每次只改一个变量 + **人工并排抽检、对漂移镜头重抽**。稳定范围约 **6–12 个场景**，更长要**6 个一批**分批做。（来源：[角色一致性指南](https://genra.ai/zh/blog/ai-video-character-consistency-guide)，抓取 2026-10-09）
2. **定妆图筛选**：文生图一次出多张，**人必须挑**（脸崩/手崩/构图跑偏），无法免人工。
3. **首尾帧中段"自由发挥"**：首尾帧只锁起止，**中段运动是模型脑补**，不合导演意图时要重来。
4. **时长拼接**：单段 ≤15s（H3）/≤10–15s（可灵/Runway），长戏要**人工切分与拼接**。
5. **成本随秒数线性膨胀**：$0.03–0.13/s × 每条多次重抽 → 重抽越多越贵；必须在"自动跑量"和"人工控成本"间取舍。
6. **音频/口型对齐**：原生音轨≠口型准确，口播类仍需 **HunyuanVideo-Avatar** 之类的对口型环节 + 人工校对。
7. **开源路线全需 CUDA**：用户 780M 一台都跑不了，只能 RunPod 或纯云 API —— 这本身是一道"必须做选择"的墙。

## 10. 给本环的推荐组合（零编程 + 无 CUDA + 可付费）

**方案 A（最省心，推荐）——整合平台 + 云 API**
- 总控：**waoowaoo**（Docker 一键、星最多、已接 MiniMax H3）或 **LocalMiniDrama**（本地感强，但出片走云）
- 定妆图/场景图：**Seedream 4.0**（中文友好、保角色）或 **Qwen-Image**（中文渲染强）
- 图生视频：**MiniMax H3**（$0.08/s 便宜、带音轨、支持首尾帧/参考，已确认可用）
- 一致性补强：跨镜换脸严重时改/补 **Vidu 2.0**（便宜+一致强）或 **可灵 3.0 Omni**（一次多镜）

**方案 B（数据私有）——RunPod 自托管**
- ComfyUI + Wan2.1（I2V/FLF2V）+ Qwen-Image；成本=显卡时长，免按秒付费，但零基础部署门槛高，需要 Claude Code 帮着搭。

**方案 C（先练手/最低成本）**
- 纯 Skill：`sanxsnr/ai-short-drama-from-zero` + `021gink/short-drama-ai-skills` 提示词库，配 Seedance/可灵网页版，先不碰代码，验证"分镜→出图→出片"手感。
