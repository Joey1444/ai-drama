## 零、先搞清三个词

| 云上的词 | 它其实是 | 比方 |
|---|---|---|
| **Pod** | 你租的一台带 GPU 的电脑 | 租一个**实验台**，按秒收费 |
| **Network Volume** | 长期属于你的硬盘 | **你自己的储物柜**，退租了东西还在 |
| **Container Disk** | Pod 自带的临时盘 | **临时台面**，退租就被清空 |

**模型有 ~59 GB。** 放临时台面 → 停机就没了，下次重下（下载期间 GPU 照样收费）。所以：**先建储物柜，再开实验台。**

---

## 一、⚠️ 两个必须先知道的坑（我原来写错了）

### 坑 1：储物柜要 **80 GB 起**，不是 50 GB

模型默认下载量是 **~59 GB**（不是我之前说的 40 GB）。加 ComfyUI 本体和运行余量，**50 GB 会撑爆**。

> **建 **80 GB**。（官方说明：Network Volume 容量**只能调大、不能调小**，所以别抠）

### 坑 2：**模板默认不挂储物柜**

模板的 `volumeInGb = 0` ——**默认没有持久盘**。如果你不手动挂 Network Volume：

> 每次停机 → 59 GB 模型蒸发 → 下次重下 **5–30 分钟**（官方原话）→ **这期间 GPU 一直计费**

**所以第 3 步"挂载储物柜"是必须做的，不是可选项。**

### 需要的环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| **`HF_TOKEN`** | 空 | **建议填**：免费的 HuggingFace 只读 token，**下载更快更可靠** |
| `H3_REF2VA` | `true` | 不需要"参考视频"模式就设 **`false`，省 19.5 GB** |

**`HF_TOKEN` 怎么拿**：去 HuggingFace 注册 → Settings → Access Tokens → 建一个 **read** 权限的 token（免费）。

## 四、六步操作

### 第 1 步：注册 + 充值
1. RunPod 注册，充 **$10**
2. 顺便去 HuggingFace 建一个 **read token**（第 3 步要用）

### 第 2 步：建储物柜（Network Volume）
1. 进 **Storage 页面** → 点 **「New Network Volume」**
2. 填：**数据中心**（选离你近的）、**名字**、**大小 = 80 GB**
   - ⚠️ 只能调大不能调小
3. 档位选 **Standard**
4. 点 **「Create Network Volume」**

### 第 3 步：开实验台（部署 Pod）
1. **Pods 页面** → **「Deploy」**
2. 选 **Network Volume** → 选刚建的那个（GPU 列表会自动筛成同机房）
3. 选 GPU：**4090**（选 Secure Cloud，因为挂卷只能用它）
4. 模板：在 Hub 里找 **Minimax-H3**（就是你给的那个）
5. 环境变量：
   - **`HF_TOKEN`** 填上你的 token
   - 不需要参考视频就把 **`H3_REF2VA` 改成 `false`**（省 19.5 GB）
6. **「Deploy On-Demand」**

> ⚠️ 储物柜**只能在部署时挂载**，之后加不了。所以第 2 步必须先做。

### 第 4 步：等下载 + 打开 ComfyUI
1. 开机后**等模型下载**：5–30 分钟（有 HF_TOKEN 会快些）
2. 在 Pod 页面找 **HTTP Services / Connect**
3. 点 **8188 端口** → 打开 ComfyUI

### 第 5 步：出第一条视频
> 来源：ComfyUI 官方 H3 教程

1. ComfyUI 里打开 **Template Library → Video → 选一个 MiniMax H3 工作流**
2. 参数按官方推荐：
   - **分辨率**：短边 768，16:9 就是 **1344 × 768**；选择器 **0.98 MP**；Multiple **32**
   - ⚠️ 别用 1.0 MP（1376×768，超上限）
   - **步数**：默认 20；**开 turbo LoRA 后 8 步**（T2V/I2V）或 **4 步**（R2V）
   - **采样器**：`res_multistep` + `simple`
3. 运行，等出片

### 第 6 步：收工——**点 Stop，不要点 Terminate**

| 按钮 | 结果 |
|---|---|
| **Stop** ✅ | 停机、停止计费、**储物柜里的模型都在** |
| **Terminate** ❌ | **连储物柜一起删，数据不可恢复** |

## 五、会悄悄烧钱的五个坑

| 坑 | 后果 | 怎么躲 |
|---|---|---|
| **没挂 Network Volume**（模板默认就不挂） | 停机→59GB 模型蒸发→每次重下 5–30 分钟，**期间 GPU 计费** | 部署时务必挂上 |
| 点 **Terminate** | 储物柜一起删 | 只点 Stop |
| 储物柜建小了 | 只能调大、不能调小，得重建 | 一次建 **80 GB** |
| 余额归零 | 官方写明：没挂卷的 Pod 会被终止、数据不可恢复 | 别让余额见底 |
| 忘了 Stop | 按秒计费，跑一夜很贵 | 用完立刻 Stop |
