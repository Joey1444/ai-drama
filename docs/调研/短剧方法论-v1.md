# 短剧方法论 v1

> **对象**：AI 生成的竖屏短剧 —— 系列《符》（都市高武 + 中式符咒），10 集试水，发抖音，MiniMax H3 生成，每集约 60 秒。
> **日期**：2026-10-09 ｜ **状态**：v1（可迭代；政策/榜单/爆款率类数据超 1 个月必须重查）
> **用途**：写每一集之前、以及每次做题材/结构/镜头决策之前，先过这份文件。
>
> **证据分级**（全文通用）：
> - 【已确认】—— 有来源、实例或数据支撑
> - 【经验之谈】—— 行业通行做法，无硬来源，但方向可信
> - 【存疑】—— 单一来源 / 榜单类时效数据 / 待实测
>
> **一级素材来源**：本仓库 `爆款题材调研-2026-10.md`、`docs/政策/平台AI创作扶持政策-2026-10.md`、`docs/方案/符/07-剧本审查要点.md`、`.claude/rules/制作红线.md`、`docs/方案/方案-v2.md`；外加本次六路调研（剧本结构 / 人物台词 / 平台算法 / 变现流程 / AI 专类 / 受限手法）。

## 零、一句话总纲（全文的根）

> **短剧不是"讲故事"，是"卖情绪"。每一秒要么在推进冲突，要么在制造缺口——做不到的秒，删掉。**

短剧是**情绪商品**：替观众在"高耗能生活"里提供**简单、直接、可控的情感释放**（"情感代糖"）。【已确认・中国青年报/光明日报口径】所有下面 9 个维度都服务于这一句。写任何东西之前先问：**这一秒，观众为什么会继续看？** 答不出来就删。

## 一、选题

### 1.1 原理
- 短剧是**情绪商品**，选题 = 选"这一部要替观众满足哪种现实中得不到的情绪"（打脸、翻身、被爱、复仇、安全感）。【已确认】
- **爆款 = 老母题 + 新切口**，几乎从不是全新题材。观众要的是"熟悉的安全感 + 意外的味道"。【经验之谈】
- 题材有**窗口期**（一般 1–3 个月）。追已过气的题材 = 白做。【已确认】
- AI 短剧**爆款率极低**：国内媒体 2026-09 口径约 **0.12%**；2026 上半年抖音新上线 AI 短剧 **22.19 万部**，破亿仅 **1055 部（≈0.47%）**。【已确认・时效数据】→ 结论：**死因是结构，不会死因"产能不够"**。

### 1.2 可执行技巧
1. **从已验证需求出发，不从灵感出发。** 数据源清单（每天扫 10 分钟）：
   - 红果短剧 / 番茄小说 榜单（App 当日榜）
   - DataEye 短剧热力榜、云合数据、猫眼专业版短剧榜
   - 抖音热点榜 / `#话题` 播放量、快手小剧场热榜
   > ⚠️ 榜单当日有效，引用必带抓取日期。
2. **母题清单**（挑一个深挖）：男频 = 战神/赘婿/神豪/都市高武/系统/修仙/玄幻/医术；女频 = 甜宠/虐恋/重生/穿越/大女主/逆袭/萌宝/年代/种田/末世囤物资。【已确认】
3. **一句话测试**：必须能一句说清"谁、在什么处境、要什么、被什么拦"。说不清 = 不能立项。
4. **匹配产能再筛**（对我们硬筛）：
   - ✅ 能拍：口播经营、末世囤物资、系统流、清醒大女主独白、种田流单人版、国风志怪单人版。【已确认】
   - ❌ 吃不着：年代群像、战争、武打、战神归来、宫斗权谋、逆袭群戏、萌宝。【已确认】
5. **差异化切口**：抄已爆母题的**结构**不抄台词，**换行业、换母题**（「不烧心」已同质化，但已成功迁移到纳鞋底、编假发网）。【已确认】
6. **AI 安全区**：AI 爆款集中在"非人角色/妖兽/修仙/异界"——**设定本身允许"不像真人"**。都市高武 + 符咒**正好落在这个安全区**（超现实元素可解释画面失真）。【已确认】
7. **看一眼政策红线**：抖音征集偏男频玄幻（都市高武在列）；"AI 仿真人漫剧激励"**排除解说剧本**；**喂未授权小说给 AI 已判赔**。【已确认】

### 1.3 新手常犯的错
- 做"自己觉得酷"的题材，不问有没有人要看。
- **追尾灯**：等上线时风口已过。
- 题材好但拍不出来（选了群戏/大场面题材）。
- 贪多：一部剧塞好几个母题，哪个都没做透。

## 二、开场（前 3 秒 / 前 10 秒 / 第一集）

### 2.1 原理
- **划走成本 ≈ 0。** 前 3 秒完播率决定约 **90% 的算法推荐量**；投放侧 3 秒没勾住，约 **30% 观众不点进剧集页**。【已确认】
- 观众判断"值不值得追"只看前 10 秒：谁跟谁斗、赌注多大、主角要干嘛。【已确认】
- 行业**六母型开场**全部是"事件"，无一种是"介绍人物"：①生死绝境/物理威胁 ②极端羞辱/地位反差 ③身份暴跌或暴涨 ④物证背叛/捉奸 ⑤反常理悬念 ⑥萌系反差（前两类最强）。【已确认】

### 2.2 可执行技巧

**前 3 秒——只干一件事：抛出极端处境（画面级危险，不是台词说出来的危险）。**
- 手法（选一）：①极端处境（血、伤、被追、被辱）②反常画面（不该出现的东西出现了）③规则惊悚（违背常理的画面异变）。
- **人物不靠台词介绍，靠他对怪事的反应定义**（镇定的=高手，崩溃的=凡人）。
- **具体到本剧**：镜 1 = 血手撑墙 + 字幕卡「最后一个会画符的人，刚死了。」——**先给怪事，再给解释**。【已确认・E1 定稿】
- **行业禁令（第一条镜头不许出现）**：起床拉窗帘 · 车行驶超 2 秒 · 大段旁白交代背景 · 咖啡厅闲聊倒水。

**前 10 秒——建齐三件事：核心矛盾 / 人物关系 / 主角目标（各一个可视信息点，零铺垫）。**
- 目标要**即时可测**：「三分钟内符咒失效我就死」才是目标，「我想变强」不是。【已确认】

**第一集——前 30 秒必须见第一个爽点（"情绪契约"的签约现场）。**
- 60 秒首集模板：0-3s 钩子 → 3-10s 三件事 → 10-25s 压到谷底 → **25-35s 金手指首爆/第一次打脸** → 35-55s 升级 → 55-60s 新危机。
- **金手指/符咒首集必须当众显威一次，不许藏。**【已确认】

### 2.3 新手常犯的错（直接从我们被毙的稿子来）
- ❌ **铺铺垫垫，前 15 秒没怪事**（原稿：「前 20 多秒就是一个人死前塞笔，套路我见过八百遍了」）。【已确认】
- ❌ **把答案甩观众脸上**，不留好奇缺口（缺口哪怕 2 秒都行）。
- ❌ **只靠氛围**：0–3 秒必须有**具体动作爆点**。
- ❌ **开场就解释设定**；❌ **把主角逼到谷底却不给反击**（长时间只虐不给反转 = 致命坑）；❌ **首集收成圆满结局**。

## 三、节奏（单集 60 秒怎么分配 / 反转多久一次 / 钩子怎么留）

### 3.1 原理
- 短剧的"快"不靠事件密度，靠**信息差**：让观众**比角色先知道**一件事。【经验之谈】
- **观众感知不到"情节"，只感知"变化"。无变化 = 划走。**【已确认】
- 情绪是**波形**：「紧→松→更紧→松→最紧」；一味爽 = 没有爽。爽感 = 压抑的解除。【已确认】

### 3.2 可执行技巧

**60 秒时间轴（本剧采用，可直接套）**：

| 区间 | 时长 | 任务 | 硬指标 |
|---|---|---|---|
| 钩子 | 0–3s | 画面级异常/威胁 | 最高浓度冲突 |
| 情境 | 3–10s | 矛盾+关系+目标 | 3 个信息点 |
| 升级 | 10–25s | **首次反转/爽点 ≤30s 必到** | 第一个爽点 |
| 打脸 | 25–45s | 本集第 2 个爽点/打脸 | 升级+打脸 |
| 峰值 | 45–55s | 情绪峰值（全片最大那一下） | 最大反转 |
| 钩子 | 55–60s | 停在**新危机** | 力度 > 本集所有冲突 |

> 铁律：**60 秒只推进一件事。** 第二条线留到下一集。【已确认・审查要点】

**节拍密度**【已确认】：**每 4–8 秒至少一次可感知变化**；**每 15–25 秒完成一个"尝试→结果"微任务**；60 秒目标 **12–16 个有效节拍**。
> ⚠️ 但**不能**把 20–30 秒的生成段拆成 4–5 秒碎片去凑数——节拍指"有意义的变化"，不是镜头数。

**反转频率**【已确认】：单集内 **15–20 秒一次**反转/小打脸；**每 20–30 秒一处情绪节点**（60 秒集 ≥2 处），形式三选一：一句暴击台词 / 一个动作冲突 / 一次信息曝光。全集间：**三集一次小反转、五集一次大高潮**；**每集至少 1 个明确爽点**（60 秒集理想 2 个）。

**钩子的三种类型**：悬念钩（未解之谜）、情绪钩（气/爽/心疼到一半被打断）、信息钩（观众已知、角色不知）。

**结尾必须停在"新危机"**：判定标准 = 本集危机解决后，是否**立刻出现一个 ①更高级别 ②指向主角/身边人 ③具名具象 ④带时限 的新压力**。四条缺一即为"软结尾"。【已确认】
- **在揭露的"前一秒"切断**，不要解释完再切。

**10 集试水的卡点编排**【已确认】：付费卡点密度（50-60 集设 5-7 个、最少间隔 5 集）等比压缩为 **首卡 E2-3（最强悬念）· 中卡 E6-7（身份/反转）· 终卡 E9-10（终极对决前）**；前 10 集**最多 2 个卡点**；**一个悬念只能卡一次**，卡在无关小事 = 失败。

### 3.3 新手常犯的错
- ❌ **中段注水**：同质反转重复（红果砍系列系数正是针对注水连载）。
- ❌ **结尾平收 / 停在噱头**：我们被毙的原结尾是"笔发光"——**发光的笔不吓人，太弱**。
- ❌ **一集想讲两件事**；❌ **重复节拍**（"订单超时"出现两次，砍一次）。
- ❌ **"把甜/爽给足了再断"**——正确做法是**断在满足的前一刻**；❌ **每集结尾都硬切**（观众疲劳）。

## 四、人物（3 秒代入 / 主角能动性 / 反派可恨 / 情绪曲线）

### 4.1 原理
- 观众不会为"陌生角色"停留，只会为"自己的处境"停留。代入 = 屏幕上的人**处境像他**，或**替他做他做不到的事**。【经验之谈】
- **爽感来自"能动性的胜利"**：主角越主动越爽，越被动越憋屈到弃剧。【已确认・"主角太被动"是我们的硬伤】
- **情绪价值 = 情感代糖**：让观众获得"简单、直接、可控的情感释放"；但爽感褪去后现实压力原封不动，所以不能只靠打脸堆砌。【已确认】

### 4.2 可执行技巧

**3 秒代入公式**：`[可见身份锚点] + [处境的反差] + [他马上想要的东西]`
- 模板：`一个值夜班的医院保安（身份），口袋里揣着爷爷留下的符纸（伏笔），此刻正被主管当众点名开除（处境），而符纸在袖里发烫（欲望/异常可见）。`
- 开局三件套：**露一个身份符号**（旧工牌/道袍布片/结疤的手）→ **一句被侮辱的台词落在头上** → **一个只属于他的异常反应**（符纸亮、瞳孔变色）。
- 本剧：黑色外卖冲锋衣 + 外卖箱 = 3 秒立住"底层打工人"。【已确认・视觉设定】

**主角能动性——每集至少一次主动选择：**
- ❌ 被动挨打 = 死。核心句：**"身份、系统、血脉和贵人只能提供条件，关键任务必须由主角判断、执行并承担代价。"**【已确认】
- **金手指给"选项"，不给"答案"**：系统可给信息/限期任务，**不能替他选**。自检句：**"去掉装置后，这一集还剩下选择吗？"** 没剩下 = 主角退化成执行者。
- **装置契约写清**：来源/功能/边界/成本/反制/升级条件/滥用后果；**"宁可少披露"，已披露的不许违反**。廉价感根源 = **事后扩权**（困境那集凭空冒出新能力 → 紧张感被追溯性清零）。
- 展示节奏三段：**第一次说明功能 → 第二次增加限制 → 第三次让主角创造新用法**。
- 本剧：**"甩不掉的绑定"（扔了笔，笔还在手里）**制造被动卷入，但**结尾必须由他主动做一次选择**（从逃 → 接）。【已确认・审查要点】

**反派——可恨 + 可信 + 递进（靠"学习"施压）：**
- **动机三问**（每个反派必答）：为什么作恶（利益/嫉妒/恐惧/立场）？能力从哪来（权/钱/人脉/情报）？为何不早动手（没放眼里/有所顾忌/在等时机）？【已确认】
- **施压三段式**：`第一次交锋平手 → 第二次反派反击、主角受挫 → 第三次主角翻盘`。**中反派至少要赢主角一次**。反派的**学习型施压**：失败后识别主角打法 → 改资源/规则/舆论 → 逼主角放弃旧优势。
- **四层反派**：小（炮灰，嚣张直白）→ 中（主要对手，阴险含蓄）→ 大（终极 Boss，从容自信，有完整价值观）→ 隐藏（揭露前后语气反转，需 ≥3 处可回溯伏笔）。台词层级递变：小反派骂骂咧咧，**大反派"笑着说最狠的话"**。
- 反常识：**观众恨的不是"坏人"，是"他做的那件具体的事"**。写反派先写"他做了什么"，再写"他为什么"。

**情绪曲线（单集小曲线 + 全剧大曲线）：**
- 单集：压抑（憋屈）→ 转折 → 释放（爽）。低谷（虐主角）**不超过 2–3 集**。
- 全剧：大爽点（身份揭示、复仇成功）**分期兑付**，不能第一集用完。
- **可量化等级**：逆袭要有"看得见的等级"（战力/符的阶数/身份），观众才知道主角在变强。【已确认・审查要点（对标《莫欺少女穷》）】

### 4.3 新手常犯的错
- ❌ **主角全程被动**（被塞、被追、被跑）——我们原稿被毙的原因。
- ❌ **反派降智**（无理由作恶/关键时刻犯傻）→ 主角赢得廉价 → 爽点贬值。
- ❌ **"势利岳父/拜金前任"当万能反派**；❌ **换皮升级**（地方富二代→省城富二代）却不改变打法。
- ❌ **爽点一次用完**；❌ **没有等级感**；❌ **人设靠台词说**（"我其实很厉害"）。

## 五、台词（和电影/电视剧完全不同的写法）

### 5.1 原理
- 电影台词求**余味**（潜台词/留白）；短剧台词求**秒懂 + 秒爽**（时长与信息密度挤压），必须**短、碎、锋利**。【已确认】
- 台词三大功能：**推进冲突 / 立人设 / 给信息**，但要**同时干**且**不能像上课**。
- **去模板化是生死线**：2026「制式台词/短剧腔」已被央媒点名群嘲——观众反感的是"模板库复制、底层情感是假的"。【已确认】

### 5.2 可执行技巧

**每句先写"功能"，再写"词"**：写前先问——这句要达成什么（逼问/威胁/打脸/立人设/给信息）？**一句话一个意思**。

**对比示例（烂 vs 好）**：

| ❌ 烂台词 | 为什么烂 | ✅ 好台词 | 为什么好 |
|---|---|---|---|
| 「这什么东西啊？」 | 谁都会说，等于没说 | 「……我扔了。」（其实没扔） | 承担动作+制造矛盾 |
| 「你活不过今晚。」 | cliché，信息为零 | 「错一笔，烧一条命。」 | 可换算成代价，能当标题 |
| 「你今日所作所为，让我对你产生了深深的怀疑。」 | 书面语/文艺腔 | 「你今天干的事，我需要一个解释。」（停）「我以为我了解你这个人。」 | 断句、去书面词、停顿代心理 |
| 「你以为你赢了吗？这事还没完！」 | 套话 | 反派（看合同，笑）「不错。」（转身，停，不回头）「你知道吗，你爸当年也是这么自信的。」 | 不说"要报复"，用有历史感的具体话制造威胁 |
| 「我绝不会屈服的！」 | 廉价口号 | 沉默地，把笔捡了起来 | 用动作代替宣言 |

**四种高爽感句式**【已确认】：
- **反击**：❌「我凭能力，不需要解释！」 ✅「（看他一眼）上次问你这个问题的人，现在在哪？」
- **揭穿**：❌「你在撒谎！」 ✅ 平静复述对方的话 → 停 → 亮物证当面砸。
- **表白**：❌「我喜欢你，愿保护你一辈子。」 ✅「（沉默三秒）因为不帮，我会后悔。」
- **反转**：❌「其实我没输，只是在等时机。」 ✅「谢谢你今天的表演。这份合同，用的是我名下的公司。」（反转须有可回看的伏笔）

**长度与句式**【已确认】：**每句 ≤ 12–15 字**，以短句为主，**用停顿/沉默当情绪载体**。

**金句公式**：短 + 狠 + 具体到能"换算"（代价/条件/身份）+ 可截图当标题。本剧「**错一笔，烧一条命**」可直接当标题。【已确认】

**篇幅占比**【已确认】：对白 60–70% / 动作描写 20–25% / **内心 OS 仅 8–12%** / 旁白字幕 0–5%。OS 只用在「观众需知但角色不能说出」的信息差上。

**去 AI 味四技巧**【已确认】：① **断句法** ② **情绪词置换**（把"她很愤怒"改成"杯子放桌上——很轻，但所有人都沉默了"）③ 方言/流行语须符合人物背景（中年权贵说"绝绝子"反而假）④ **沉默即台词**（标"停顿 2 秒"）。提示词里加一句：**「减少内心 OS，让观众从动作和对白自行理解情绪，不要直接解释。」** 并附**风格锚点例句**（比空说"写口语点"有效得多）。

**避免"说教感"**：设定**边打边给**，每集只喂**一条规则**且由剧情带出；代价/规则**只说一次**且由当事人说（本剧由濒死者说成遗言）；去掉"其实/你知道的/我来告诉你"这类引导词。

**台词长度硬约束（本机实测）**：中文约 **4.1 个可发声字/秒**（按此反算每句时长）；**单镜台词 ≤ 1–2 句**（H3 长对白口型必崩）。【已确认・制作红线】

### 5.3 面向「单人镜头」的台词加固（我们唯一的叙事主力）【经验之谈/存疑・建议实测】
- **把"对手"物化/场外化**：电话/微信语音（反派当画外音，主角只有特写反应）、屏幕特写当第二演员（来讯/转账/倒计时）、以"物"代"人"（符咒、旧照片、门缝外的影子）。
- **独白只给结论不给过程**：60 秒内 OS 控制在 **2–3 句**，其余交给微表情（手抖、瞳孔变化、符纸发烫）。
- **台词负担再分配**：把"立人设"塞进**反击台词**，"给信息"塞进**物证特写**，"推冲突"塞进**电话那头**——三者分开，才不挤成一堂课。

### 5.4 新手常犯的错
- ❌ **连续两句解释性台词**（像上课）——我们犯规过。
- ❌ **台词当文字**：写完不检查"念出来要几秒"。
- ❌ **说教式金句**（"我们要相信正义"）——金句要"狠"不要"正"。
- ❌ **人人说一样的话**（外卖员和老墨应完全不同）。
- ❌ **用独白把设定讲完**（第一集就"我本是某某传人……"）；❌ **用台词交代画面能说的事**。

## 六、视觉与镜头（竖屏构图的特殊规律）

### 6.1 原理
- **竖屏不是裁切，是重写**：横屏思维直接裁竖屏 → **切头**。【已确认】
- **横向视野只有 16:9 的 1/3 强** → 远景/全景靠横向铺陈信息，**竖屏基本失效** → 实际以**中景、近景、特写**为主。【已确认】
- 空间靠**纵深**（前/中/后景分层），不靠横向。

### 6.2 可执行技巧
- **画面三区构图**【已确认】：**上 1/3 = 脸与表情；中 1/3 = 手部动作与道具；下 1/3 = 字幕与关键物件**。
  - 本剧：**符咒特效放中 1/3（手上/胸前），脸放上 1/3，字幕放底部**。
- **景别分工**【已确认】：近景=情绪与证据，中景=对峙，远景=仅交代空间。
- **镜头时长 3–7 秒**【已确认】，60 秒/集 ≈ **10–18 镜**（本剧分镜基本 3 秒/镜）。每镜**只承担一个动作**，禁"走路+转身+哭+递东西"叠加。
- **节奏卡口**【已确认】：前 3 秒必须给证据/表情/动作；15 秒内完成第一次理解；30 秒内给第二次反转；超 30 秒按 15 秒小段拼接，每段以画面锚点收尾。
- **色彩即语言**：固定颜色约定承载信息，三集内建立。本剧：攻=红、守=蓝、咒=黑、**手绘=金**；**画面里只有符可以发光**。【已确认・视觉设定】
- **重新入画规则**【已确认】：段末离画要写"段末离画/退场"；重新入镜要写"段初自门口入画回到桌旁"；未写移动的人，相邻段之间**位置/朝向/依托物不得漂移**。

### 6.3 新手常犯的错
- ❌ 用横屏思维构图（两侧留白、横向并列信息）→ 切头。
- ❌ 字幕压在平台 UI 区（被进度条/昵称挡住）。
- ❌ 镜头太长（>7 秒不换）——竖屏小屏极易走神。
- ❌ 颜色/视觉标识每集变——观众记不住。

## 七、AI 生成特有的技巧与坑（重点）

### 7.1 已火的 AI 短剧怎么做
- **形态**：主流是**漫剧**（2D/国风插画风），其次「AI 仿真人剧」。漫剧天然绕开真人脸恐怖谷。【已确认】
- **题材自觉适配短板**：爆款集中在"非人角色/妖兽/修仙/异界"——设定允许"不像真人"。**红果 2026-09 总榜前五被 AI 漫剧包揽**。【已确认・时效】
- **叙事换挡**：从纯"打怪升级"转向**"错位开局 + 金手指"**——因为 AI 不擅长慢慢铺垫情绪。【已确认】
- 已验证单人爆款：《包子里的真心》（13 亿）、《发配边关》（40 亿）、《咱家剑宗团宠小师妹》（200 亿，被吐槽注水）、《非妖哉》（"一人手搓"）。

### 7.2 一致性（跨镜同一张脸/同一身衣服）—— 这是命根子
**官方工作流铁律**【已确认】：
- **身份来自参考图，不来自文字；且文字会"打赢"照片**——同一 seed 下，写了外貌句的人脸会和参考图不一致。
- 提示词**只写"年龄段 + 指向照片的指针"**：`苏晚，三十岁上下，与参考照片完全一致——同一张脸、同一发型与服装。`
- **别写**：族裔、发色/发型、脸型、眼睛颜色、皮肤、体型、眼镜、妆容——**任何镜头都不要**。名字用本名（`苏晚`）**不要用 `ID_A`**。
- **照片通过"可见面部"绑定**：每个有参考图角色的镜头，**脸必须入画且清晰**（3/4 或侧脸皆可），且**镜头结束时脸仍在画内**（收尾帧是下一镜继承依据）。**背对镜头/转头收尾 → 身份重掷。**
- **首尾帧锚定**：用上一镜末帧作下一镜首帧，跨剪辑防变脸。
- **提示词逐字节稳定**：每镜对发型/服装/特征的措辞**完全一致，只改动作和场景**。
- **锚点（发夹、耳钉、领口、符纹）写在"角色资产"里，不写进镜头描述**（写进描述会每镜漂移）。
- **重滚率现实**：实测约 **25%**（问题集中在手/表情/运镜）。纪律：**小批量先试，只重跑坏镜头，坏的从锁定参考图重滚**。
- **头号杠杆是 image-to-video**：从锁死的参考图起步，而非 T2V。
- 残酷真相：模型**无跨镜记忆**，无法 100% 消除漂移；稳定范围约 6–12 镜，更长要"每 6 镜一批"+ 抽检重跑。【已确认・方案 v2】

### 7.3 运动与机位：可靠 vs 必崩
- **运动四要素公式**【已确认】：一次运动只写「**一个动作 + 一个方向 + 一个速度 + 一个必须保持不变的东西**」。最后一项最易漏、却唯一可验收（如"轴线不变""门框始终在画面左缘"）。
- **机位与动作"互相抵消"是隐蔽翻车点**：如"他快步冲出门"配"镜头极缓推进"= 两条速度指令，模型只执行一条且**选哪条不由你决定**。修法：用**关系动词**连接（跟随、匹配速度、被他甩在后面）；说不清就让**机位不动**——"一个能读的固定镜头强过一次方向不明的运动"。**【已确认】**
- **可靠**：慢而稳的运动。**必崩**：fast/violent camera moves → 抖动+畸变。**一镜一相机运动**，禁叠加。
- **运镜术语是"方言"**：不跨模型照搬词表（有的只收 `push in` 不收 `dolly in`）。
- **模型不能生成自定义音效或画面文字** → **符咒文字必须后期贴图**。

### 7.4 用声音和后补画面（AI 短剧的命根子）
- **声音是奇观的另一半**：环境音、低频轰鸣、突然静音、提示音——最廉价的"未来感/压迫感"。【已确认】
- **口型不贴的解法**：每句台词后立刻加 **"listens, lips remain closed"（听者闭嘴）**；更狠的是**少给正面大特写讲台词**——用侧脸、背身、局部（手/道具/符咒发光）承载台词。【已确认】
- 环境音归"声景"不进对话标签；旁白标 `off-screen voiceover` 并保持屏内角色闭嘴。
- 后期（ffmpeg，本机 $0）补：光晕/辉光、色散、粒子、白闪冲击帧、扫描线/噪点、调色/颗粒。【已确认】

### 7.5 「AI 味」：来源与减轻
- **可识别特征**【已确认】：电影化平滑运镜、画面稳如三脚架、现代商业调色（青橙/高对比）、完美居中、自动加商店/人群/广告牌、自动配 BGM、摆拍直视镜头、**皮肤过度平滑**、跨镜漂移、灯光过匀。
- **⚠️ 关键提醒（针对 H3）**【经验之谈】：很多"加瑕疵"技巧（handheld、film grain）是为**写实系模型**设计的，在 H3 上**无脑堆会加剧抖动失真**。**H3 更稳的路线是减法**：缩短面部特写停留、多用侧/背角度、靠运动模糊和快切。
- **快剪造连续**【已确认】（AI 的结构性优势）："同一个情绪的崩塌，用几条各自身份不同的短镜快切，往往比一条不间断表演更像完整的崩溃"——每条 2–3 秒只留"到位瞬间"，**让观众脑子补中间**。

### 7.6 必崩清单（H3 硬红线，勿碰）
| 禁 | 为什么 |
|---|---|
| 多角色同框（含双人对话） | 最不可靠，直接崩 |
| 群戏 / 大场面 / 远景 | 768P 远景糊，单段撑不起 |
| 复杂动作 / 追逐 / 打斗 | 跨镜连不上 |
| 单镜台词 > 1–2 句 | 口型不贴 |
| 画面内可读文字 / UI | AI 必糊 → 后期贴 |

**双人镜常见翻车点**【已确认】：角色互换（服装相似/标签模糊）· 两人都动嘴 · 多出手臂（交接缺接触阶段）· 道具变形 · 剪辑后视线断裂 · 环境重置。

> 取巧：**科技感靠"信息密度"不靠"场景密度"**——后期叠 UI/HUD/扫描线，台词写未来黑话，屏中屏（主角对设备独白）。

### 7.7 新手常犯的错
- ❌ **指望模型解决一致性**（不现实，要靠"不去拍需要一致的镜头"）。
- ❌ **用生成器生成文字/UI**（必乱码）；❌ **一镜到底长镜头带对白**（口型全崩）。
- ❌ **忽视后期与声音**（应反过来：生成占 50–60%，后期+声音占 40%）。
- ❌ **无脑给 H3 加 handheld/film grain**（反而更崩）。

## 八、失败案例：什么样的短剧会死，死在哪一步

### 8.1 行业真实数据【已确认・时效】
- 投放素材**前 3 秒没勾住 → 约 30% 观众不点进剧集页**。
- **超过 60% 的观众在第 1–3 集弃剧**（主因：剧情可预测、画质差、主角脸出戏）。
- 付费墙（第 10-15 集）处**超 90% 用户看到付费窗即退出**；单集完播率跌到 **15%–20%**。
- AI 短剧爆款率约 **0.12%**（2026-09 媒体口径）。

### 8.2 五步死法（按发生顺序）
1. **前 3 秒没钩住** → 死 30% 曝光（开场空镜/旁白/世界观）。
2. **前 3 集没签成情绪契约** → 死超 60%（首集无爽点、金手指不显、主角被动）。
3. **中段注水** → 每 20-30 秒无情绪节点，节拍稀。（**"台词像说教"= 零信息落差的台词，直接删**）
4. **主角被动** → "咸鱼"人设只能是**伪装**，不能是真状态；每分钟都要有主动选择。
5. **结尾软** → 噱头替代威胁。

### 8.3 我们的坑 → 对应死法（自查表）
| 我们的坑 | 违反的规则 | 死法 |
|---|---|---|
| 开场太慢 | 前 3 秒画面级钩子 | §8.2-1 |
| 结尾是噱头不是威胁 | 结尾"新危机"四条件 | §8.2-5 |
| 主角太被动 | 每集至少一次主动选择 | §8.2-4 |
| 台词像说教 | 每 4-8 秒可感知变化 | §8.2-3 |
| 每集没有爽点 | 每集至少 1 个明确爽点 | §8.2-2 |

## 九、制作流程（工业化标准流程 vs 我们的 MVP）

### 9.1 成熟团队标准流程（从选题到上线）
| 阶段 | 产出物 | 卡点 |
|---|---|---|
| ① 选题立项 | 题材判断 + 一句话梗概 | 题材窗口期 |
| ② IP / 原创 | 授权或原创纲要 | **版权红线（AI 侵权判赔）** |
| ③ 故事大纲 | 母题/主线/爽点地图 | 能否一句话说清 |
| ④ 人物小传 | 人设 + 反派 + 情绪曲线 | 主角能动性 |
| ⑤ 分集大纲 | 每集钩子 + 反转 + 结尾 | 集间钩子衔接 |
| ⑥ 分集剧本 | 可拍摄剧本 | 台词时长/密度 |
| ⑦ 筹备 | 选角/勘景/服化道/分镜 | 成本 |
| ⑧ 拍摄 | 素材 | 进度/预算 |
| ⑨ 后期 | 剪辑/配乐/调色/字幕 | **节奏与声音** |
| ⑩ 送审备案 | 备案号 | **合规（微短剧备案制）** |
| ⑪ 上线投放 | 投放素材 + 分账 | **投流 ROI** |
| ⑫ 数据复盘 | 完播/留存/付费 | 迭代 |

> **标准周期（成熟团队 35 天 SOP）**【已确认】：策划 1–7 → 筹备 8–14 → 拍摄 15–21（实拍 5–7 天）→ 后期 22–28（**均镜长 ≤3 秒**）→ 审核上线 29–35。**AI 剧把中段压到 1 周内**：脚本 1 天 + 人设半天 + 分镜半天 + 生图 1 天 + 生视频 1 天 + 配音半天 + 剪辑 1 天 + 审发半天 = **6–7 天/部**。最常被跳过的是策划阶段的**"平台对接"**（不谈收不收/系数/独家就开机 → 做完全平台不收，直接死）。
>
> **成本量级**【已确认・2026-10】：真人精品 ~150 万；AI 精品漫剧（120 分钟）**10–20 万**、3–4 人 2–3 周；AI 仿真人剧 6–10 万；**AI 漫剧 800–1200 元/分钟（真人 1/5）**。生成单价：Seedance 2.0 720P 0.6 元/秒、1080P 1.5 元/秒。**我们 10 集试水：纯制作 1–3 万可落地**。
> ⚠️ **坑**：只算生成费、不算人力/返工/算力峰值 → 实际常是报价的 **2–3 倍**。
> 行业成本占比：制作 27% : 投流 35% : 平台分账 20% : 达人 8% : 盗版 10%，**团队利润 <10%**。（详见第十一章）

### 9.2 我们的最小可行流程（MVP，单人/小团队）
核心差异：**把 ⑧ 拍摄替换为"AI 生成"，⑨ 后期比重大幅上升，⑪ 先自然流试水再谈投流。**
```
选题 → 一句话梗概 → 故事引擎 → 人物小传 → 分集大纲(钩子表)
   → 单集剧本 → 分镜(逐镜标 H3 手法+风险) → 定妆/关键帧(参考图锁脸)
   → H3 逐镜生成(带原生对白) → 本机 ffmpeg 剪辑/字幕/调色/音效
   → 一致性抽检重跑 → 出口成片 → 发布(+AI 标识) → 数据复盘
```
- **最容易被跳过、跳了就会死的一步**：**分镜阶段的"风险镜标注"**。把可能崩的镜头（两手同框、快速动作）**提前标出并准备后备拍法**，比事后重跑省 10 倍时间。【已确认・E1 已有实践】
- **另一条不能跳**：出口前的**一致性抽检 + 台词时长核对 + 生成后字幕校对**（whisper 转写中文默认**繁体+半角**，需归一化，否则相似度虚低 58.6%→归一化 100%）。【已确认・本仓库 gotcha】
- **保留"确认后生产"闸门**，制止无人值守烧钱。【已确认】
- **最容易被跳过导致死掉的 3 步**：① **平台对接**（不问收不收/分账系数/独家要求就开机）；② **版权留证**（不留生成过程，被搬运无法主张版权——武汉案赢在留了创作过程）；③ **首集 3 秒钩子测试**（有效播放折算率仅 ~40%，6 成流量白给）。
- **试水剧的 KPI 不是赚钱**：以 5000 万播放为盈亏基准，AI 剧回本率 <1.3%。**10 集试水的目标是验证"平台收不收 + 完播率 + 是否给流量"**，据此决定是否量产。

### 9.3 新手常犯的错
- ❌ 跳过分集大纲直接写剧本 → 集间钩子断裂。
- ❌ 跳过风险镜标注 → 生成完才发现崩。
- ❌ 后期时间给太少 → AI 感重、节奏散。
- ❌ 不做数据复盘 → 每部都从零开始。

## 十、【专章】受限制作下，怎么做到"看不出来是受限的"

> **前提**：只能 **单人镜头 + 特写 + 极简场景**；禁多角色同框、禁群戏、禁大场面、禁连续打斗。
> **总原则**：**可被感知的缺失才可怕。** 观众不会去数"这里少了第二个人"，只会隐约觉得"信息没给到"。打法不是"掩盖没有画面"，而是**把信息载体从"人"换到"声音/物件/屏幕"**——这三样都不受限制。
> **三根支柱**：① **载体换位**（对手戏→声音；打斗→道具与音效；世界观→旁白与面板）② **限制世界观化**（把"只有一个空间"写成职业设定）③ **类型承诺**（第一集就确立"这是单人/直播/接单"的规则）。

### 10.1 十条成熟替代手法（每条：先例 / 怎么落地 / 局限）

**1. 正反打不拍脸（对话拆成单人镜头）+ 轴线锁定**
- 先例：好莱坞对话戏基本语汇；行业指南明确双人戏"避免并排平均站，按戏剧关系排站位"。【已确认】
- 落地：两人戏永远拆成 A 单人镜（含过肩）+ B 单人镜交叉剪辑。定一条"关系轴"：**A 永远看向画面右外侧、B 永远看向画面左外侧**，观众自动缝合成"面对面"。提示词写死机位与视线：`人物位于画面左1/3，中近景，目光投向画面右外侧，前景虚化的肩部入画`；反打镜像。用**前景遮挡法**（虚化的肩膀、杯子、门框）暗示"对面有人"。
- 局限：**两个单人镜都看同一侧 → 对视感立刻崩**；必须用视线标签固化。

**2. 电话 / 传音 / 远程对话**
- 先例：**《Phone Booth》(2002)、Locke (2013，全片一人困车内打电话)、The Guilty (2018，调度员全靠电话)、Sorry, Wrong Number (1948)**。【已确认】
- 落地：把"对手"永久处理成画外音/电话/对讲/录音/语音条。分镜模板三镜循环：①主角特写（听）→ ②设备特写（来电/消息/波形）→ ③主角反应。**只需一张单人镜**。
- 高武落地：师父/组织/反派通过"**传音玉符 / 加密耳机 / 系统语音 / 电话**"沟通——用世界观顺带把手法合理化。
- 局限：全靠电话会显得廉价且像广播剧；需偶尔补一层"对方那边的环境音"；60 秒内电话戏最多承载 1–2 个反转。

**3. 主观视角（POV）+ 手部特写**
- 先例：《Hardcore Henry》(2015)；伪纪录片 POV（《女巫布莱尔》《REC》）；胡金铨、徐克的招式特写。【已确认】
- 落地：**手是最容易生成、且完全不涉及"变脸"的近景主体**。提示词例：`第一人称视角，一只右手持毛笔在黄符上落笔，朱砂晕开，浅景深特写`。
- 符咒落地：画符、掐诀、点睛、燃符全是手部动作戏。
- 局限：POV 太久会晕；一旦 POV 里要出现"对面的人"就得生成人脸，反而暴露限制。POV 与第三人称近景交替。

**4. 物件叙事 / 特写道具**
- 先例：**《Cast Away》(2000) 的 Wilson（一个排球承载全部孤独与对话）**；希区柯克麦高芬（《Psycho》赃款）；中式符/剑/令牌本就承载身份与法力。【已确认】
- 落地：让一个道具当"第二主角"。把**道具特写插入镜（insert shot）**当节拍器——每个情节点插一个道具特写，替代打斗与群戏。必须把道具做成**资产**（固定材质、颜色、纹样、灯下反光），跨集复用。
- 高武落地：**一张符的"变化"就是特效本体**——朱砂发光→燃烧→碎裂，**用一张符演完整场"斗法"**。本剧：那支笔（永远在他身上）、老墨的半张残页（边缘焦黑程度 = 剧情进度）。
- 局限：道具戏密度过高会让 60 秒变静态、像广告；每 10 秒需插一个"人体动作"节拍（挥笔、拍桌、踉跄）。

**5. 画外音 / 独白 / 旁白（单人爆款结构）—— 本项目命门**
- 先例：**抖音「不烧心文学」13.7 亿播放确证单人经营流可行**；末世囤物资剧（《我在末世开超市》《末日囤货，零下70度独霸安全屋》）；电影侧 **Locke / All Is Lost (2013) / Buried / 127 Hours**。【已确认】
- 落地：第一人称旁白扛全部信息，画面只负责"证据/情绪"。结构：旁白抛钩子（"我以为……"）→ 画面给证据 → 反转。竖屏节奏：前 3 秒旁白+视觉证据，15 秒首个理解点，30 秒二次反转。镜头三件套循环：单人近景 + 空镜 + 道具特写。
- 高武落地：主角内心 OS 解释"这套符怎么用/什么规矩/敌人弱点"——**世界观解说成本全由旁白吸收**。
- 局限：旁白过量 = 有声小说化。旁白必须与画面对位（说的与看到的有落差或呼应）。

**6. 声音先行 / 声音补叙事**
- 先例：《大白鲨》(1975) 先声后形；广播剧纯靠声音叙事。【已确认】
- 落地：**声音先出，反应镜头后给**。分镜公式：①主角面部听到（特写）→ ②声源空镜/道具特写 → ③主角反应（特写）。"没拍到的动作"全部由声音承载（脚步、门响、玻璃碎、惨叫、符纸爆燃、手机震动，全走音效库，不花生成成本）。
- 高武落地：打斗全部放画外，画面只有"主角听声后的表情 + 手部收紧"。用**音效密度**（3 秒内叠 5 层打击音）制造"打得很凶"的错觉。
- 局限：纯声音段落不宜超全片 15 秒，否则画面显空；音效要"过一点"（夸张）才盖得住。

**7. 屏中屏 / 设备独白（系统面板）**
- 先例：Screenlife 流派 **《Searching》(2018)、《Unfriended》(2014)、《Profile》(2018)**；本土化即"系统面板"。【已确认】
- 落地：主角对手机/系统面板/全息符纹独白——**面板就是"第二角色"**。分镜：①主角特写 → ②面板特写（UI 与文字**后期贴图**）→ ③主角反应。
- 高武落地：都市高武的"系统流"天生适配——眼前浮出符纹系统面板，任务/等级/功法全 UI 化，反派"隔着屏幕"放狠话；系统语音 = 画外音。
- 局限：满屏 UI 会像游戏录屏；文字要少、要大、竖屏可读。

**8. 转场与蒙太奇掩盖（暴力发生在画外）**
- 先例：**《Psycho》(1960) 浴室戏 78 个短镜拼贴，刀从未触及身体**；《Reservoir Dogs》割耳切到画外；中式"意到笔不到"。【已确认】
- 落地：每个无法生成的场面都用**三镜掩盖法**：①动作起势特写（手抬起/符举高）→ ②空镜或环境反应（爆燃、尘土、门被撞开）→ ③动作结果（人已倒地/对手消失）。**中间关键那一帧永远不给。** 快切（每镜 0.5–1.5 秒）制造打斗节奏。
- 高武落地：整场"斗法"用符燃 + 光效 + 尘土 + 主角踉跄四元素拼出来，**全片不出现第二个人**。
- 局限：同一手法连用三集以上会被识破；必须轮换掩盖元素（这场烟雾、下场水花、下场手机碎屏）。

**9. 空间极简化的合理性设计**
- 先例：密室片 **《Room》(2015)、《Saw》、《Cube》**；美剧 bottle episode（《Breaking Bad》"Fly"集）；情景喜剧单布景。【已确认】
- 落地：把"只有一个场景"写成世界观。给主角一个固定**据点**（符箓工作室/出租屋/地下法坛/安全屋），所有事发生在据点内或通过通讯传进来。用**"重复空间 + 变化细节"**（灯光、道具、时段、断电、着火）制造"这个空间在变化"的错觉。
- 高武落地：**"符师的工作室/法坛"天然合理——符师本就是闭门画符、靠符与外界对话的人，空间极简是职业设定，不是省钱。**
- 局限：重复空间看久了会腻，必须靠"空间的时间变化"与"道具进出"更新。

**10. 极端特写代替动作 + 局部暗示（用局部代替全景）**
- 先例：动作片插入镜（impact shot）；《指环王》用局部暗示大军；"一扇扇亮起的窗"代替全景。
- 落地：H3 对连续动作弱 → **全部改"动作前后两镜"**（转身、抛掷、甩手、下蹲都拍结果不拍过程）。奇观用**尺度对比/局部**：本剧 E9「不拍全景，拍**一整条街的窗玻璃一张张亮起**」；E5「脚下巨型符阵逐圈亮起，人只占一个小点」。【已确认】
- 局限：快切节奏要跟上；需要一个"锚点"（人/物）提供尺度参照。

### 10.2 天然适配"单人 + 极简"的类型片（可直接借壳）【已确认】
- 电话惊悚片：《Phone Booth》《Locke》《The Guilty》《Sorry, Wrong Number》
- 独角戏/单人片：《Locke》《All Is Lost》《Buried》《127 Hours》
- 密室片：《Room》《Saw》《Cube》
- Screenlife/桌面电影：《Searching》《Unfriended》《Profile》
- 监控/CCTV、直播视角（竖屏原生）、审讯室、经营流（《不烧心》13.7 亿）、末世囤物资、伪纪录片/第一人称恐怖（《女巫布莱尔》《REC》）
- **映射到「都市高武+符咒」**：最匹配 = **直播视角 + 系统面板 screenlife + 经营流（帮人驱邪接单）+ 电话/传音惊悚**。主角是个"接单驱邪的符师/主播"，白天出摊、晚上闭门画符，靠面板与传音跟外界打交道。

### 10.3 "看不见的限制"的三个判断标准
1. 观众**事后回想**才发现"好像从来没有两个人同框" → 载体重分配成功。
2. 观众**吐槽的是剧情/节奏**而非"画面怎么这么空" → 限制已被世界观吸收。
3. 观众**不会问"第二个人在哪"** → 类型承诺在开头就立住了。

### 10.4 常犯的错
- ❌ **为省成本拍"空"**（没信息的空镜 → 划走）。省成本 ≠ 省信息。
- ❌ **单人镜头拍成"自言自语"**（缺对手戏张力）——要用画外音/物件/设备当"对手"。
- ❌ **不敢用大特写**——竖屏+小屏，大特写是**优势不是妥协**。
- ❌ **类型中途换**——类型必须贯穿全系列；**第一集就要给"类型承诺"**，否则后面每次"没同框"都被当成穿帮。

## 十一、平台与算法 + 变现商业

> ⚠️ 本章数据/政策抓取于 **2026-10-09**。变动频繁（红果 2/7/9 月连续改政），**超过 1 个月务必重查**。

### 11.0 五条直接影响决策的硬结论
1. **抖音"有效播放"门槛远高于红果**——抖音付费剧需**单集完播 ≥70% 单集时长**才计入；红果**仅需 ≥3 秒**。抖音播放"含金量"高但难拿，红果好拿但单价低。
2. **红果 AI 剧活动有"单部物理时长 ≥60 分钟"硬门槛**——我们 10 集 ×60 秒 = 10 分钟，**不达标** → 走不了红果 AI 剧激励；只能走**抖音端原生**，或大幅加集。
3. 抖音流量大盘偏**现实向**，红果偏**爽感脑洞**；但抖音的 **AI 扶持征集偏男频玄幻**——两套逻辑，别混。
4. 海外**纯中式玄幻/修仙不灵**，能迁移的是"内核情绪"（婚姻/背叛/身份），外壳必须本土化。
5. 60 秒短集在抖音是"完播率游戏"，在海外（45 集起、每集 2 分钟）是"追更游戏"，同一素材不能通用。

### 11.1 抖音
- **推荐权重**（第三方拆解，**【存疑】**）：2026 推流从"24 小时赛马"改"**7 天长效赛马**"（长尾占比约 68%）；权重序 = **收藏率 > 复访率 > 铁粉互动 > 5 秒完播 > 整体完播 > 评论质量 > 点赞 > 转发**（完播由第一跌至第五）。
  - ⚠️ 另一来源仍称"完播率最重要之一"——**两说并存**；稳妥 = 完播率与收藏率都做到位。
  - "收藏高、复访低"会被判**"标题诱骗收藏"降权**。
- **流量池**：分 **6 级**；冷启动池约 100–300 次曝光，门槛约 **3 秒留存 ≥55% / 5 秒完播 ≥40%**（存疑）。
- **分账**：**IAP 分成 2026-02 起提至 70%–80%**（付费走小程序）；免费走端内。
- **10 月新规**：竖屏 + 总时长 ≥70 分钟 + 上线满 30 天 + 自然流量破 250 万 → 除最高 15% 分账外，可再获**最高 60 万元现金激励**；取消固定保底，改"先跑量、再奖优"。整体：15 亿保底、80% 分成、单部最高 150 万头部激励、续作 20% 上浮、2 亿创新题材专项。
- **AI 仿真人剧/漫剧政策**：7/29 系数——仿真人/3D 漫/2D 漫维持 40、表情包动态漫 10、**解说漫 1→10**；奖励按红果播放热度值分档（起步 5000 万热度 → 1 万/4 万/2 万；最高 7000 万热度 → 5 万/20 万）。
- **8/3 新规**：对**都市情感、破局成长、家庭温情、都市逆袭**四类 AI 仿真人剧设硬要求（画面/人物一致性/动作衔接/音画同步），**打击"模板人物、固定镜头、一键生成、日更数十部"的粗放铺量**。
- **真人结合 AI**：额外 **3%–20%** 内容分成，单月最高 30 万/部；门槛：真人实拍 ≥20%、AI 画面 ≥5%、总时长 ≥100 分钟、竖屏。
- **对我们的含义**：把"都市高武"往抖音 AI 重点品类 **"都市逆袭/破局成长"** 靠（而非纯玄幻），才吃政策顺风。

### 11.2 快手
- 走**端原生**（App 内分发，播放/完播/互动直接考核，不经小程序）。
- 20 亿结构：8 亿分账 + 2 亿现金孵化 + 10 亿专属流量；分账从"投流 ROI 广告"转向 **GMV 共享**。
- 活动（至 11/30）：时长达标 15% + 完播达标 15% + 系列续作 20%，**合计最高 50%，单部封顶 20 万**。
- 用户/题材：三线及以下 + 农村，偏**男频逆袭/战神/神豪**与家庭伦理；追求"爽感密度"；完播门槛 **≥30% 单集时长**。
- 差异化：10–100 万粉分账补贴提至 25%；下沉作品超 5000 万播放额外现金；乡村短剧大赛 500 万奖池。
- **漫剧与真人短剧付费用户重合率仅 38%**（62% 为纯增量用户）。

### 11.3 红果
- 2026/7 **DAU 1.68 亿**；**45 岁以上用户过半**，超六成来自三线及以下。
- 免费 + 广告（看十几秒广告解锁下一集）+ 金币任务。
- 分账公式：`当月新增有效时长 × 时长单价 × 漫剧类型系数 × 版权系数`；**完播门槛仅 ≥3 秒**，行业平均完播率约 70%。
- **万播单价一年内从约 100 元跌至约 5 元（跌超 95%）**。
- **"优质 AI 剧生产活动 2.0"（10 月生效）取消系列剧规模系数**（原"第二部起翻倍、同 IP 多季最多 20 万/部"归零）→ 靠同 IP 批量续集"蹭奖金"失灵，改由**单部真实热度**说了算。门槛：单部物理时长 ≥60 分钟，起付 5000 万热度，7000 万热度 → **20 万/部**；时长系数 ≥120 分钟=1、60–120 分钟=0.5。
- 2 月新政：漫剧 4 类扩 **7 类**；**仿真人维持 60 倍**；2D 从 50 降至 40；**AI 仿真人解说漫归入动态解说仅 5 倍**。
- 保底转向纯分成：AI 剧本 S+ 级保底**从 5 万降至 1 万**；8 月单月拦截下架违规 AI 剧 **8689 部**；真人保底预算超 15 亿。
- 新"**3D 制作适配度评分**"：剧本 85 分以上优先签约 + 流量；限制霸总/太太等同质题材。
- **误解澄清**："取消系列系数 ≠ 不能做系列"——故事好、单部热度够，续作照样给钱，只是不再因"系列身份"额外奖励。

### 11.4 番茄小说（IP 源头）
- 与红果同属字节、同一负责人，形成"**小说 IP 供养短剧**"闭环；番茄 IP 改编短剧收入 2025 年增长 **8 倍**。
- **开放 6 万+ 原创 IP 免费改编**，头部 IP 改编费**平台 100% 补贴**。
- 剧本保底 **4 万–20 万**（分成从 20% 提至 **40%**）。
- **含义**：**最便宜的上游素材库**——要做 IP 改编，优先进这里找免费 IP 并申领补贴。

### 11.5 四平台口味对比
| 平台 | 用户画像 | 题材偏好 | 分账模式 | AI 剧态度 |

| 抖音 | 年轻为主 | **现实向**（都市日常 672 亿、乡村/种田/年代合计 807 亿） | 保底+分账，IAP 70–80% | 扶 AI 仿真人剧（现实向四类），**打粗放铺量** |

### 11.6 海外（ReelShort / DramaBox / TikTok）
- 市场：H1 2026 海外 IAP 收入 **12.7 亿美元**；**北美月收入 5692 万美元 = 全球 32.82%**（日本近 9 倍）；北美 CAC 高达 $5.28（峰值 $15）。
- 付费：欧美走**内购+订阅**（ReelShort/DramaBox/NetShort）；东南亚/拉美走**免费**。**"付费点卡/金币"不是欧美主流**（常见误解）。
- 时长/集数：海外 AI 剧平均 **45.6 集**（29–75）；日本短动画每集 **2 分钟**、30 集；对比国内 AI 漫剧平均 **712 集**。ReelShort 美国用户日均 35.7 分钟（超 Netflix 24.8）。
- 题材：H1 海外 AI 剧百强 **情感 68% / 逆袭 24% / 狼人 16%**；本土剧付费转化 **8%–10%**；本土剧份额 27%→**46%**。
- **中式题材**：国内"重生逆袭+东方玄幻"→海外换"离婚反击+狼人身份"——**"技术相同，故事语法完全不同"**。纯中式玄幻/修仙不灵；能迁移的是**内核情绪**（婚姻/背叛/身份）。**我们出海需把符咒换成当地可懂的超能力/狼人/魔法外壳，保留"身份反转+复仇"内核。**
- **TikTok**：走**免费/流量分成**（非内购）；1–7 月创作者分成破 1.1 亿美元。与独立 App **互补非替代**。

### 11.7 合规红线（对"赚钱"最致命）

- **AI 生成内容必须显式标识**。
- **肖像权/声音权**：真人风需授权（¥500–1500/张脸）。
- **许可**：部分开源工具为 CC BY-NC-SA（禁商用）或非 OSI 许可——商用前必查。
- **儿童相关情节是红线**（红果 8 月拦截含儿童负面情节 AI 剧 138 部）。
- **喂未授权小说给 AI 已判赔**。

### 11.8 变现真相（分账 / 投流 / 保底）【已确认・2026-10-09，时效强】

**分账（免费 IAA 已成主流）**
- 按**有效播放**分账，非总播放。折算率各平台不公开：红果约 **60%**、抖音约 **40%**（阈值 ≥70% 集时长）、快手约 **50%**（≥30%），行业均值约 40%。剔除 <3 秒、同用户重复、异常流量。
- 万次有效播放单价【2026-10】：短视频平台 **5–12 元**，长视频 50–100 元。**红果一年内从 30–100 元跌到 5–10 元（跌 >90%）**。
- **红果口径：100 万有效播放 ≈ 500–1000 元**——与"爆款神话"差三个数量级。头部分账 = 全国流量天花板（《盛夏芬德拉》44 亿播放才分 1600 万），普通剧是零头。
- 抖音付费端分成 = 充值 **6%–7%**（2025-10 官方）；2026-02 起 IAP 分成上调至 **70%–80%**（平台/内容方口径，**勿与用户充值口径混**）。
- ⚠️ **现金流坑**：2026 结算周期从 1 个月延到 **3 个月**，首期回款仅 **35%**。

**投流（信息流买量）—— 极小团队绝不该自己投**
- 付费短剧成本结构：制作 **7.5%**、投流 **82.5%**、平台抽 10–20%；**版权方净利仅流水 3%–5%**。
- 巨量引擎占投流 73%、腾讯广告 17%、快手 8%。
- **ROI 真实值**：成熟买量团队稳定 **1.03–1.07**（几乎不赚）；普通项目 **<0.8**（亏）；行业均值 1.05–1.2。
- **回本率**：2024 付费剧 <30%；**AI 剧 2026 上半年能回本不足 1.3%（约每 77 部 1 部打平）**；AI 剧爆款率 0.16%（约 635 部出 1 部）；**64% 作品播放不足 100 万**。
- **结论**：走**免费分账**（平台承担买量）或交平台/代投；别赌"以小博大"（幸存者偏差）。

**保底 / 承制 / 分账剧**
| 模式 | 谁出资 | 内容方拿什么 | 风险归属 |
|---|---|---|---|
| 承制 | 平台 | 一次性承制费 20–50 万/部，利润仅 **5%–8%** | 平台扛市场风险，要求规模化产能 |
| 保底 | 平台 | 按评级预付保底（剧本 4–20 万；成片 20–35 万） | 平台（**2025-09 起红果取消**） |
| 分账剧 | 内容方自筹 | 纯按公式分成，无预付 | 全归内容方，高风险 |

- **重大变化**：红果 2025-09 起取消承制/引入剧保底；2026-02 批量暂停未开机真人项目、取消保底承诺。转向"纯分账 + 精品化"。全国握有平台保底额度的公司 **不到 10 家**。
- **含义**：我们无产能、无爆款史 → **拿不到承制/保底**，现实路径只有"**分账剧 + 平台 AI 激励**"。

### 11.9 IP 改编与版权判例（红线）【已确认・2026】
- **抖音/番茄漫剧 IP 库**：开放 **50 万+** 番茄 IP。**个人可申 1 长 5 短/月**（机构 5 长 10 短）。排除动态/静态解说剧、AIGC 推书视频；AI 仿真人剧、3D/2D 动画、沙雕漫剧可改。**授权不可撤销**，逾期未完成算违约。
- 抖音漫剧扶持三项：① 番茄 IP 改编费补贴 ② 成片框架保底（月产出 ≥5 部）③ 头部精品单片采购。免费渠道 **90% 收益给版权方**。
- **判例（2026）**：① 武汉江岸区法院——AI 漫剧整部搬运**判赔 2 万**，并**首认 47 集 AI 微短剧为"视听作品"**（因脚本/分镜提示词/剪辑/配音/字幕构成"连续性、实质性智力投入"）。② 和平区法院——**把小说"喂"给 AI 生成漫剧 = 侵权**（标准：接触 + 实质性相似，**画面全 AI 重绘也侵权**），依据最高法 2025-09-07《涉人工智能纠纷意见》第 12 条。
- **版权归属看"人类智力投入"**：无锡案（反复调提示词 + 独立脚本）= **认原创（判赔 10 万）**；上海案（简单罗列提示词）= **无著作权**。
- **含义**：用番茄 IP **必须走官方 IP 库申请**，别直接扒书喂 AI；自研剧本要**留证**（提示词、调参步骤、生成过程录屏）并及时版权登记。

### 11.10 AI 短剧特有变现路径
- 平台 AI 激励/大赛：抖音"AI 创变者计划"最高 10 万奖金；腾讯视频 AI 短片大赛；快手 AIGC 创投（**优先漫剧**）；爱奇艺 AI 短片大赛最高 3000 美元。

- 免费渠道分成：抖音 90%、快手最高 90%、B站最高 80%、百度 3 倍分成。
- ⚠️ 大赛奖金是"入场券"不是"生意"——别为奖金做亏本片。

### 11.11 对本戏的落地清单（都市高武+符咒 · 竖屏 10 集×60s · 发抖音）
1. **主营抖音端原生**：**抖音漫剧扶持明确收"都市高武"——正好是我们的题材**；把它包装进抖音 AI 重点品类"都市逆袭/破局成长"，纯玄幻调性在抖音大盘吃亏。
2. **10 集×60 秒不满足红果 AI 剧活动**（需单部 ≥60 分钟）——要吃红果激励须扩到 60 分钟+（约 60 集），或改走抖音端原生。
3. **完播按抖音标准**：单集完播冲 ≥70%；每集结尾强钩子 + 引导收藏 + 第 3/5 天评论区补料触发复访。
4. **变现走"平台 AI 激励 + 免费分账"**：别自己投流（ROI 1.03–1.07 几乎不赚）；**试水 KPI = 平台收不收 + 完播率，不是收入**。
5. **IP 走官方入口**：自研剧本要留证（提示词/调参/录屏）；若要改编，走抖音/番茄 IP 库官方申请（**个人 1 长 5 短/月，授权不可撤销，占坑前先确认能做完**）。
6. **合规先行**：《微短剧发展管理办法》9/1 起三类备案；AI 标识；儿童情节红线。
7. **出海换壳**：钩子留"身份反转/复仇"，符咒换狼人/魔法外壳；集数扩到 45 集+、每集 2 分钟。

### 11.12 常犯的错
- ❌ 以为"播放量 = 钱"（抖音 100 万播放结算基数可能只有 40 万）。
- ❌ 以为"AI 门槛低 = 容易爆"（0.5% 破亿率，平台在反向下调低质供给权重）。
- ❌ 以为"取消系列系数 = 不能做系列"。
- ❌ 一上线就砸钱投流（内容没验证）。
- ❌ 用红果真人榜判断 AI 漫剧口味。
- ❌ 忽略 AI 标识/备案（下架/判赔风险）。

## 十二、开机前检查清单（写每一集之前，逐条过）

> 用法：**每一集开写前，从上到下打勾。任何一条打不了勾，先解决再写。**

### A. 选题与全局（只在开剧时过）
- [ ] 题材能用**一句话**说清（谁/处境/要什么/被什么拦）？
- [ ] 有**已验证爆款**做对标？同题材是否已同质化？
- [ ] 落在**单人 + 特写 + 极简**产能内（无群戏/大场面/连续打斗）？
- [ ] 版权/合规过关（原创或官方授权；AI 标识待加）？

### B. 单集结构
- [ ] **0–3 秒**有具体动作爆点（画面级危险，不是氛围、不是铺垫）？
- [ ] 前 10 秒给齐**矛盾 + 关系 + 目标**（目标可即时测量），且**没解释世界观**？
- [ ] 全集**只推进一件事**？
- [ ] 单集内 **15–20 秒一次**反转/小打脸，**20–30 秒一处情绪节点**？
- [ ] 本集有 **≥1 个明确爽点**（憋屈→释放的曲线完整）？
- [ ] **结尾停在新危机**（满足"更高级别/指向主角/具名具象/带时限"四条件）？
- [ ] 卡点安排不违背"一个悬念只卡一次"、前 10 集 ≤2 个卡点？

### C. 人物
- [ ] 主角**每集至少一次主动选择**（不是全程被动）？
- [ ] 金手指只给"选项"不给"答案"？（自检："去掉装置后这一集还剩选择吗"）
- [ ] 反派答满**动机三问**，且**至少赢主角一次**、失败后会改变打法？
- [ ] 目标靠**行为**立，不靠台词说？有**可量化等级感**？

### D. 台词（逐句过）
- [ ] 每句都承担**推进/立人设/给信息**之一？废话删干净？
- [ ] 没有**连续两句解释性台词**？没有"其实/你知道的"引导词？
- [ ] 每句 **≤12–15 字**？代价/设定**只说一次**且由当事人说？
- [ ] 有无**可当标题的金句**？金句是"狠"不是"正"？
- [ ] **内心 OS ≤ 8–12%**？OS 只讲"不能说"的，不讲"懒得拍"的？
- [ ] 台词按 **4.1 字/秒**算，与镜长匹配？**单镜台词 ≤ 1–2 句**？
- [ ] 重复节拍砍掉了吗（同一信息不出现两次）？

### E. 视觉与镜头（对 H3 红线逐镜过）
- [ ] 每镜**最多 1 人**？无多角色同框？
- [ ] 无群戏/大场面/远景？奇观用**局部暗示/尺度对比**？
- [ ] 无复杂动作/打斗？动作**只拍结果不拍过程**？
- [ ] 画面内**无可读文字/UI**（全部后期贴）？
- [ ] 人物用**参考图引用 + 本名**（不写外貌描述句）？**每镜收尾脸在画内**？
- [ ] 提示词对发型/服装措辞**逐字节一致**，只改动作与场景？锚点写在角色资产里？
- [ ] 运动遵守**四要素**（一动作+一方向+一速度+一不变量）？一镜一相机运动？
- [ ] 画面构图符合**三区**（上脸/中手/下字幕）？颜色标识符合本剧体系？
- [ ] 光：**只有符/屏幕可发光**，其余压暗？
- [ ] 字幕内容不压平台 UI 安全区？

### F. AI 生成与后期
- [ ] **风险镜已标注**（两手同框、快速动作等），且有后备拍法？
- [ ] 需要一致性的镜头，是否**能改成不需要一致的拍法**？
- [ ] 台词每句后已加"听者闭嘴"标注？长内容已转旁白（标 off-screen voiceover）？
- [ ] 声音设计（环境音/音效/低频）已规划？**声音是否承担了画面补叙事**？
- [ ] 后期特效清单（光晕/粒子/色散/白闪/调色/颗粒）已列？
- [ ] 生成后**必过**：一致性抽检 + 台词时长核对 + 字幕校对（whisper 转写需**归一化为简体**再比对）？
- [ ] xfade 转场的**时间轴偏移**已算（字幕 SRT 按转场后时间轴）？

### G. 交付
- [ ] AI 生成标识已加？
- [ ] 竖屏 9:16 / 规格符合目标平台？
- [ ] 已留可截图的**传播点**（金句/名场面）？

## 十三、最反常识的 5 条

1. **短剧不是讲故事，是卖情绪（"情感代糖"）。** 故事只是爽点的载体——先定"这一部满足哪种情绪"，再编故事。爆款率约 0.12%，死的都是"结构"不是"产能"。
2. **"限制"不是短板，是风格。** 单人 + 特写 + 极简，正是多个十亿级爆款的**主动选择**（不烧心 13.7 亿、种田流 40 亿）；把限制写进设定，观众以为是我们选的。
3. **A. `AI 短剧的"电影感"来自后期与声音，不来自生成模型本身。`** 后期 + 声音应占 40% 精力；声音是奇观的另一半。**B. 一致性真正的解法是"永远不拍需要一致的镜头"，而不是指望模型**——模型无跨镜记忆。
4. **结尾必须停在"威胁"，不是"奇观/噱头"。** 发光的笔不吓人；贴门喊「笔呢。」才吓人。判定：新危机要满足"更高级别 + 指向主角 + 具名具象 + 带时限"。
5. **台词越短越好、越"不解释"越好，且主角必须"被迫做选择"。** 每句 ≤15 字、OS ≤12%、删掉所有解释性句子；被动挨打的主角 = 死。
