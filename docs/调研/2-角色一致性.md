# 第 2 环：角色一致性（AI 短剧最大难点）

> 调研日期：2026-10-09 ｜ 服务对象：清华 SIGS 材料硕士，零编程，本机 AMD 780M 核显无 CUDA，可用 RunPod + MiniMax H3
> 研究法：二手优先（高星 README / 行业横评 / 综述），关键数字用 GitHub API / 官方文档核实。

---

## 0. 一句话结论

**跨镜头"长得一样"目前没有 100% 全自动方案**。工业界共识是"**锚定资产 + 概率重跑**"：先用参考图/身份嵌入**锁死一张脸**，再用带主体参考的图生视频模型逐镜头生成，最后人工抽查重跑漂移帧。对零编程用户，**云上的"主体参考 / reference-to-video"API（MiniMax S2V-01、Vidu Q3）是最短路径**；LoRA 一致率最高但必须上 RunPod 自己训。**多角色同框**是全链路里最脆弱的一环。

| 方法 | 原理 | 训练 | 一致率 | 成本/时间 | 零编程可用 | 云 API | 本环难度 |

## 3. 四类短剧：本环难度分层

| 类型 | 本环难度 | 为何 | 首选方案 |
|---|---|---|---|
| **1. AI 真人风** | ★★★★★（最难） | 人脸是"高维细节"，观众对漂移极敏感；逐帧概率性"幻觉"无法根治 | LoRA（真人脸） + 主体参考/S2V 逐镜生成 + 抽查重跑；可用云 API 起步 |
| **2. AI 动画/漫剧** | ★★★☆ | 二次元脸特征更"符号化"，风格一致比人脸生物特征更宽容；但风格漂移另需控制 | **角色 LoRA + sref（风格参考）/Style Bible 帧**；huobao-drama、wind-comic 专为此做 |
| **3. 图文解说** | ★★（最易） | 多为静态图 + 旁白 + 字幕，无逐帧人脸生物特征要求 | 参考图锚定即可；Pixelle-Video/剪映图文成片基本够用 |
| **4. 混合（真人素材+AI）** | ★★★★★ | 真人实拍素材与 AI 生成画面**跨模态对齐**最难；换脸/替换要保纹理与光照 | 真人先做**身份锚（LoRA 或授权人脸）**→ AI 替换/特效段用同锚生成；此环自动化程度最低 |

## 4. 本环「卡点」：哪里无法全自动、必须人工介入（硬性要求）

1. **漂移无法 100% 消除（最大卡点）**。阿里云技术文明确："无法做到 100% 完全消除漂移"，只能压低概率；必须**预留重跑/重试机制**。中途采样（1/3、2/3 帧）发现漂移要"直接终止任务、调参重跑"——**这是人工判断，无法全自动**。
2. **参考图要人工筛选**。需正面/45°侧/微表情/标准光照 4 张（LoRA 则 20-50 张），**禁用随机生成帧当参考**；凑图、筛图、标注是纯人工活。
3. **多角色同框最脆弱**。MiniMax S2V-01 **仅支持单主体单图**；能多参考的（Vidu Q3 1-4 图、即梦 50 输入）也常在多脸互相"污染"。治本方案 PuLID Flux II（双角色）仍需本地 GPU 工作流。
4. **LoRA 训练要 GPU + 调参**。本机 780M 无 CUDA → 必上 RunPod；rank 8-16、lr 1e-4~1e-5、20-50 epoch 需试错。
5. **肖像权合规**。行业已从"盗脸"转向"买脸"，现价 **¥500-1500/张脸肖像授权**（微博/闲鱼/小红书交易），需人工谈授权，非技术能解决。
6. **整合项目仍有半成品**：jellyfish（原型）、waoowaoo（测试期）不能直接产片；ArcReel/huobao-drama 相对可用但仍需配 API Key、逐阶段人工审核。

## 5. 落到用户画像的推荐路径

- **零编程 + 无 CUDA + 预算敏感**：优先 **ArcReel**（5405★，今日仍更新，Docker 一键 + Web 工作台 + 多供应商 + 费用追踪，支持 MiniMax；跨镜一致性靠资产图复用）或 **huobao-drama**（15893★，但**禁商用**需注意授权）。
- **二次元/漫剧**：**wind-comic**（MIT，可商用，cref+sref+视觉 LLM 抽 8 维 DNA + 分数<75 自动重生成，正好治漂移）。
- **要最高一致率**：在 RunPod 上用 **ostris/ai-toolkit / kohya_ss** 训角色 LoRA（4-8h/次），再喂云端图生视频。
- **最短起跑线（先用现成 API 跑通）**：MiniMax **S2V-01**（单主角）+ **Vidu Q3**（多参考）逐镜生成 —— 与用户已有的 MiniMax H3 同生态，零 CUDA。
- **图文解说**：Pixelle-Video（Windows 一键包）最省事，本环几乎不是瓶颈。
