## 二、逐项验证

### 1｜多镜拼接 + xfade 转场 ✅

3 个 5s 镜头（`shots/shot_01..03.mp4`）用 `xfade=transition=fade:duration=0.4` 串联。

**实测**：成片 14.20s。抽帧 t=4.72s 可见深蓝紫与彩色条纹**半透明混合**，确认转场生效。

![转场证据](../../_validate/grid2.png)

### 2｜任意尺寸归一 → 1080x1920 ✅

`shot_02` 故意做成横屏 1920×1080。经
`scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920`
后正确 cover 裁剪，无变形、无黑边。

![尺寸归一](../../_validate/grid.png)

### 3｜BGM 混音 ✅

`amix=inputs=2:duration=first:normalize=0`，BGM 经 `volume=0.12` 压低，不盖对白。
（`normalize=0` 是关键——否则 amix 会按输入数均分音量，把对白也压低。）

### 4｜响度归一 ✅

`loudnorm=I=-14:TP=-1.5:LRA=11`（短视频平台通用口径）。
**实测 Input Integrated = -13.9 LUFS**，与目标 -14 差 0.1。

### 5｜中文字幕烧录 ✅

`subtitles` filter + `FontName=Microsoft YaHei`，白字黑边。
抽帧确认中文、英文数字（`9:16`）均正常渲染，无乱码、无方框。

### 6｜9:16 竖屏导出 ✅

```

aac, 32000, 2      (audio)
14.200000s, 668 KB
```

### 7｜时间轴映射 ✅

脚本自动计算并打印每镜在成片中的起点：


## 三、这一轮踩到并修掉的四个坑

| # | 坑 | 真相 | 处置 |
|---|---|---|---|
| 1 | `npx skills add … -g` 11 个技能**全报 Failed** | 报的是 PromptScript 目标不支持全局；**Claude Code 目标其实装成功了** | 别重装，直接查 `~/.claude/skills/` 是否有软链 |
| 2 | 方案 §5 写"whisper.cpp/FunASR 转写→字幕" | Drama-Skills 的 `short-drama-edit` 明确"**字幕逐字取自剧本**"，台词是写死的 | 字幕走**剧本→SRT**；ASR 只做**校验** |
| 3 | 转场后字幕整体错位 | xfade 是两镜**重叠**，每个 0.4s 转场让后续镜头起点**前移 0.4s** | `build.py` 自动算映射；SRT 按转场后时间轴写 |
| 4 | ASR 相似度虚低到 58.6% | whisper 中文默认输出**繁体 + 半角标点** | 比对前 `zhconv` 繁转简 + 去标点，相似度回到 100% |
