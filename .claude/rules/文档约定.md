# 文档与目录约定

> **什么时候读**：新建文件、移动文件、不确定东西放哪时。

---

## 放哪

| 内容类型 | 放哪 |
|---|---|
| 项目总则 / 索引 | `CLAUDE.md`（**只索引，正文放 rules/**） |
| 项目规则（按主题） | `.claude/rules/*.md` |
| 角色定义 | `.claude/agents/*.md` |
| 硬门 / 提醒脚本 | `.claude/hooks/*.py`（在 `settings.json` 注册） |
| 执行手册 / 系列方案 | `docs/方案/` |
| 调研、分环研究 | `docs/调研/` |
| 调研、爆款研究、agent 经验 | `docs/调研/` |
| 评审意见 | `docs/评审/` |
| 平台政策 | `docs/政策/` |
| 验证记录 | `docs/记录/` |
| 系列方案与剧本 | `docs/方案/<系列>/` |
| agent 输出模板 | `templates/`（**只读引用，不重写**） |
| 工具脚本 | `scripts/` |
| 剧集工作区 | `docs/方案/<系列>/`（剧本文档按 00/01/02… 编号） |
| **临时交接件** | 项目根（如 `交接清单.md`）——**看完即焚**，见规则 5 |

## 命名

- 素材类：`素材-<事件>-<YYYY-MM>.md`
- 政策类：`平台<主题>-<YYYY-MM>.md`（**月份是保质期标记**）
- 记录类：`<主题>-记录.md`

## 规则

1. **正文不写进 CLAUDE.md**——CLAUDE.md 是入口索引，按主题放 `rules/`
2. **每个规则文件开头写「什么时候读」**——让按需加载有依据
3. **带日期的信息必须写日期**，并在超过 1 个月时提示重查
4. **迁移文件 / 密钥纪律 / 上下文经济** → 见**全局** `rules/work.md` 与 `rules/info.md`，**本项目不重述**（重复会漂移）。
   本项目特有的一条：依赖扫描器只认 markdown 链接，**认不出反引号里的文件名**，所以移动前还要补一次针对性搜索。
5. **临时交接件（`交接清单.md` 之类）是"看完即焚"，不是常驻文档。**
   它是**给下一个接手的人读一次**的，读完要把知识**分门别类挪进常驻文件**，**再删掉原文件**：

   | 内容 | 挪到哪 |
   |---|---|
   | 进度、卡点、下一步 | `项目状态.md` |
   | 实测数据、踩过的坑、操作步骤 | `docs/调研/<主题>-实操手册.md` |
   | 成本 / 部署 / 许可 / 本机能力 | `.claude/rules/事实基线.md` |
   | 章节性的长期决策 | `项目状态.md` 的「关键决策」表 |

   ❌ **不要在交接件里修修补补再留着**——它会一直躺在仓库里误导后人。
   ⚠️ 挪之前先核对：**交接件里的判断可能是错的**（实测过一次：它说"25 分钟没出片是可疑的"，实际只是慢，差点误杀一条正常任务）。
