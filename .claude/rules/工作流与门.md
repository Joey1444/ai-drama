# 工作流与阶段门

> **什么时候读**：判断下一步做什么、能不能进入下一阶段。

---

## 阶段与依赖

```
G1 设定门 ──→ G2 剧本门 ──→ G3 生产门 ──→ G4 成片门
 世界观简报      单集剧本       分镜+提示词      成片
```

**依赖链：上游未定完，不许进下游。** 这是硬约束。

## 各门通过条件

| 门 | 位置 | 通过条件 | 谁来判 |
|---|---|---|---|
| **G0 立项门** | 开工前 | 方案 + 验收标准 + 团队就位 | 用户 |
| **G1 设定门** | 世界观定稿 | ① `producer` 判定可拍 ② `audience-proxy` 判定"会看下去" | producer + audience-proxy |
| **G2 剧本门** | 单集剧本定稿 | 四维评分 **≥ 14/20** 且无单项 ≤2 | 评分 + audience-proxy |
| **G3 生产门** | 送生成前 | ① 分镜 + 提示词齐备 ② producer 复核无红线违反 ③ **用户显式确认** | producer + 用户 |
| **G4 成片门** | 导出前 | ① `build.py` 通过 ② `verify_asr.py` ≥ 90% ③ 抽帧肉眼确认 | 脚本 + 用户 |

## 归属规则

- **涉及花钱的生成，必须过 G3 且用户显式确认**——不允许"预览即确认"
- **改世界观** → 回到 G1 重过门
- **改剧本** → 回到 G2 重评分

## 四维评分（G2 用）

| 维度 | 5 分 | 1 分 |
|---|---|---|
| 钩子强度 | 前 3 秒就是钩子 | 开头平淡 |
| 反转力度 | 出人意料且合理 | 结尾平收 |
| 实害具体度 | 具体到能看见 | 只有抽象概念 |
| 可拍性 | 完全符合红线 | 多角色同框/大场面 |

**总分 < 14 → 重写；任一维度 ≤ 2 → 直接打回。**

> 完整定义见 [验收标准.md](../../验收标准.md)。
