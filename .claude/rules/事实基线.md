## 视频生成：MiniMax H3

| 项 | 内容 | 核对日期 |
|---|---|---|
| 开源 | **2026-08-03 开源权重**，两个 checkpoint：`FL2VA`（文生/首帧/尾帧/首尾帧）、`Ref2VA`（参考式） | 2026-10-09 |
| 音频 | **保留原生 32kHz 立体声**，官方原文："32 kHz stereo, generated in the same pass" | 2026-10-09 |
| 单段时长 | **官方 API：4–15 秒**（整数秒）。⚠️ **但本地 ComfyUI 实测更宽松**——模板自带的 demo 就跑的 **20 秒**，成片 `20.042s` / `481 帧` **正常产出、没报错**。所以"15 秒上限"是**托管 API 的约束，不是本地推理的硬墙** | 2026-10-10 实测 |
| 时长 ↔ 耗时 | **近似线性**。实测：**4.46s 镜（107 帧）采样 86 秒**；**20s 镜（481 帧）采样 9 分 30 秒**（均 20 步）。越长越贵，且一致性与画质**未验证是否下降** | 2026-10-10 实测 |
| 时长取整 | 时长按 **17 帧网格**取整：请求 4 秒 → **107 帧 → 实际 4.459s**。⚠️ **字幕/时间轴必须探测真实文件时长，不能拿请求值累加**——13 镜能差出近 7 秒 | 2026-10-10 实测 |
| 分辨率 | **本地部署只出 768p（竖屏实际 768×1366）**，需上采样到 1080×1920；2K 需走 MiniMax 托管 API | 2026-10-09 |
| RunPod 部署 | 模板 **`a1nkufhzxq`**（Fast prompting FL2VA + 本地 Qwen-VL，本地推理非 API）；**建 Pod 时必须加 `allowedCudaVersions:["13.0"]`**，否则 CUDA 起不来；模板自带 **110GB 卷**，**不用建网络卷**（网络卷停机也计费） | 2026-10-09 实测 |
| RunPod 价格 | Community 云 **5090 $0.69/h** · Secure 云 4090 $0.89/h；网络卷 $0.07/GB/月 | 2026-10-09 实测 |
| 首次启动 | 下 ~70GB 模型，**约 15–25 分钟**；盘占用约 69GB | 2026-10-09 实测 |
| **出片耗时** | **20 秒**任务全程约 **30 分钟**（`executed in 14:08` = 采样 20 步 9:30 + 模型加载与解码）。⚠️ **进度条走 `\r`，`tail` 看不到——别据此判断"卡死"**，差点误杀过一条正常任务 | 2026-10-09 实测 |
| **参数映射** | `t2v-pod.json`：时长改 **`134 PrimitiveFloat`**（秒，经公式换帧）；尺寸改 **`172 ResolutionSelector`**（`132` 的 width/height 是废值被连线接管）；**进度条的 `x/20` 是采样步数，与时长无关** | 2026-10-09 实测 |
| ✅ **权重已齐** | Pod 上 **`FL2VA` 与 `Ref2VA` 均已就位**（各 20G）。**参考式可跑**。（早前"只下了 FL2VA"的记录已过期） | 2026-10-10 实测 |
| ⚠️ **Pod 上无 T2I 模型** | Pod 的 `checkpoints/`、`diffusers/` 全空 → **Pod 自己出不了静态图** | 2026-10-10 实测 |
| ✅ **但 T2I 已可用（外部接口，免费）** | **OpenRouter 独立图片接口** `POST https://openrouter.ai/api/v1/images`，body `{model, prompt}` → 返回 `data[0].b64_json`。**注意：不是对话接口**（cc-switch 的模型列表只含对话模型，不在此列）。<br>**免费模型 `inclusionai/ming-image-0.1-design` 实测可用**，出图 **1440×2560**，质量满足定妆帧要求（正脸/闭嘴/纯黑无 logo/冷调）。<br>key 在 `~/.claude/token.txt` 的 `OpenRouter=` 行 | **2026-10-10 实测** |
| ⚠️ **参考式 vs 文生式的速度差 4 倍** | **双参考（Ref2VA，2 张图）采样约 39 秒/步**（20 步 ≈ **13 分钟**）；**单参考约 9 秒/步**（≈ 3 分钟）。且双参考显存吃到 **31.7/32GB（5090 贴顶）** | 2026-10-10 实测 |
| ⚠️ **切换模式会重载 20GB 模型** | 在 T2VA(`fl2va`) 与 Ref2VA(`ref2va`) 之间来回，ComfyUI 每次**重载模型**（日志可见 `Requested to load MiniMaxH3`）→ 单次多耗 1–2 分钟。**批处理要把同模式的镜排在一起** | 2026-10-10 实测 |
| 🆕 **单次生成内多镜**（官方支持，本项目此前未用） | 形如 `[Shot 1] … [Shot 2] At 00:03.500, the camera cuts to …`；配套 `<scenetrans>`（台词跨剪辑延续）、`<cutoff>`（片尾台词截断）。官方还有一条：**只改景别/微角度时优先用运镜而非切** | 2026-10-10 查官方规范 |
| **SSH** | 公钥**只在创建 Pod 时注入**，重启无效；查 `PUBLIC_KEY` 环境变量长度可验证 | 2026-10-09 实测 |
| **ComfyUI 认证** | 装了 `ComfyUI-Login`，密码存 `<ComfyUI>/login/PASSWORD`；**文件不存在则一律 401**；`POST /login` 首次提交即完成设置 | 2026-10-09 实测 |

> ⚠️ **完整实操与 8 个坑见 [`docs/调研/H3-RunPod-实操手册.md`](../../docs/调研/H3-RunPod-实操手册.md)**，含 UI→API 格式转换的三个必修坑、模型文件名不匹配、LoraManager 空值等。

> ⚠️ **两处需纠正的旧认知**：① 本地**不是**原生 1080×1920；② **没有** RunPod 官方 H3 部署专页，"L40S 官方推荐"实为社区口径。

## 许可（MiniMax H3 Community License）

- ✅ **可商用**
- ⚠️ **必须显著标注模型名**（商业产品上显示 MiniMax H3）
- ⚠️ **美国 / 英国 / 欧盟 / 韩国属排除地区**，当地用户须申请许可（**用户在肯尼亚，不受限**）
- ⚠️ 仅 **base model** 开源（另 2 个模块仍专有）；禁止用其输出蒸馏其他模型

## 已知的坑

1. **xfade 会提前时间轴**——每个转场让后续镜头起点前移
2. **字幕别走 ASR**——剧本台词是写死的，ASR 只做校验
3. **whisper 中文默认吐繁体 + 半角标点**——比对前必须归一化
4. **策略类信息保质期 1 个月**——平台政策尤其
