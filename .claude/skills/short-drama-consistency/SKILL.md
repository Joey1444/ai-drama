# 短剧跨镜一致性技能

解决 AI 视频生成「模型无跨镜记忆」导致的**场景漂移、色温跳变、角色五官漂移、道具状态丢失**。

---

## ★ 当前主线：锚图 + Ref2VA 参考式（2026-10-10 实测有效）

```
分镜完成
    ↓
① 出「锚图」（H3 T2VA 一条干净镜 → 抽帧）：
     · 场景锚：每场景一条空镜（老巷 / 废弃屋）
     · 身份锚：每角色一条 chest-up 镜（★ 必须含服装，见下）
    ↓
② 每镜按需挂参考（Ref2VA，节点 137=参考1、139=参考2）：
     · 环境镜  → 只挂【场景锚】（单参考，快）
     · 出脸镜  → 挂【场景锚 + 身份锚】（双参考，锁场景+锁脸）
    ↓
③ 正文声明每张图（★ 不声明则第二张不生效，见下）
    ↓
④ 生成 → 抽帧验收 → 坏镜重抽 → 后期归一 → 成片
```

**为什么有效**（实测对比）：原方案只给 2 个出脸镜绑图、其余纯 T2VA →
同一"老巷"在不同镜里砖墙颜色不同；改成**每镜都挂场景锚**后，背景与锚图一致。
证据：`docs/生成留证/符/EP001/验证-双参考/M02对比图.png`。

### ⚠️ 四条硬约束（全部实测踩过）

| # | 约束 | 后果 |
|---|---|---|
| 1 | **挂了图必须在正文声明** | 只写 `<Picture 1>` 时**第二张不被使用**。必须补：`<Picture 2> is the … that supplies the location …`，并在 `retention_analysis` 说明它保留什么 |
| 2 | **身份锚必须含服装**（chest-up 或更宽） | 只给一张脸 → 参考图里没衣服 → 模型**自己发明衣服**，且**自带运动品牌 logo**；提示词的 `no logo` **压不过它** |
| 3 | **锚帧不要抽说话帧** | 会把张嘴状态咬进后续所有镜头（方法论 §7.2 / §3-A5） |
| 4 | **双参考慢 4 倍** | 实测 **39 秒/步**（单参考 9 秒/步）→ **必须开 turbo**（见 `drama-pipeline`） |

### 锚图怎么出（本机 $0 + 1 次生成）

1. 用 H3 **T2VA** 写一条干净镜的提示词（空场景 / chest-up 正脸，**脸或场景要完整入画**）
2. 生成 → 本机 `ffmpeg -ss <t> -frames:v 1` 抽帧，或 `scripts/pick_frame.py`
3. **抽帧标准**：主体清晰 · 光线均匀 · 无第二人 · 不糊不畸变
4. 放进 `输入/参考图/`，同场景所有镜共用同一张

## 2. REF 槽位管理

格式（逐字）：
```
REF-<slot>（顺序：<n>）· <项目相对路径>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
```
`用途` 只能取：`身份` / `造型状态` / `地理` / `构图` / `尺度` / `效果` / `起始帧` / `结束帧` / `风格`

| 用途 | 用在哪 |
|---|---|
| 身份 | 角色定妆帧 |
| 地理 | 场景锚 |
| 造型状态 | 特定造型帧 |
| 起始帧 | 首帧关键帧 |

## 3. 跨镜曝光/色调归一化（后期，$0）

H3 逐镜独立生成 → 曝光/色温会漂。**后期统一**（`_validate/build.py` 已有曝光归一）：
选每场景首镜首帧为基准 → 算亮度/色温统计 → 对同场景其余镜套同一 LUT/曲线。

---

## 4. LoRA 训练（触发条件）

满足任一才做：① 漂移率 > 30% 且重跑不收敛 ② 跨集复用角色 ≥ 3 集 ③ 关键出脸镜反复重抽 ≥ 5 次。
数据 20–50 张多角度图；**每角色单独训、推理分开加载，不混合**。

## 5. 升级路线：T2I 关键帧链路（**前置未满足，暂不执行**）

> **定位**：`docs/方案/升级路线.md` 明写「不在当前主线」。
> **三条件未满足，直接跑会报缺权重/缺模型**：
> 1. ❌ Pod 模板带的是 **Qwen-VL（视觉理解）不是 Qwen-Image（文生图）**，**根本没有 T2I 模型**（`checkpoints/`、`diffusers/` 全空）
> 2. ❌ `run-comfyui-image` 与 H3 模板能否合并成同一 Pod **未验证**
> 3. ⚠️ 磁盘只剩 20G，Qwen-Image int8 要 16.1G → 要先腾空间

**升级后的形态**：T2I 出**静态关键帧**（比"视频抽帧"清晰、且能出三视图）→ I2VA 从此起步。
**触发条件**：锚图法仍不达标的场景 / 需要每镜精确构图 / 要系列级角色三视图。
