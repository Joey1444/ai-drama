# 短剧跨镜一致性强化技能

> ## ⚠️ 前置条件（2026-10-10 producer 复核修正）
>
> **本 skill 的「关键帧链路」属于「后续升级」，不是当前主线。**
> `docs/方案/升级路线.md` 明写「定位：不在当前主线。现在只登记、不执行」。
> **当前三条件未满足，直接跑会报缺权重/缺模型：**
> 1. ❌ Pod 上**只有 FL2VA，缺 Ref2VA**（事实基线）→ 参考式跑不了（19.53GB 需另下）
> 2. ❌ Pod 模板带的是 **Qwen-VL（视觉理解）不是 Qwen-Image（文生图）** → T2I 关键帧那步没有模型
> 3. ❌ `run-comfyui-image` 与 H3 模板能否合并成同一 Pod **未验证**
>
> **当前唯一零成本可用的是「自锚定」**：H3 出 4s 正脸镜 → `pick_frame.py` 抽帧 → 绑 Ref2VA identity。这条 E1 已在用，也只需它。
>
> **升级触发条件**（满足任一）：跨镜漂移 > 30% 且重跑不收敛 / 要开第 2 集需系列级一致 / 某出脸镜反复重抽不收敛。满足后再按本文档执行，并先补齐上面三条前置。

解决 AI 视频生成「模型无跨镜记忆」导致的曝光漂移、色温跳变、角色五官漂移、场景几何不一致、道具状态丢失等核心痛点。

## 核心策略：关键帧链路（T2I → I2VA）—— ⚠️ 见顶部前置条件

```
分镜完成
    ↓
short-drama-image-prompts 生成《图片提示词.md》（定妆/首帧/场景/道具）
    ↓
RunPod 同 Pod 跑 Qwen-Image (T2I) 出所有关键帧
    ↓
pick_frame.py 校验关键帧质量（正脸/闭嘴/清晰/无遮挡/光照均匀）
    ↓
short-drama-video-prompts 生成《视频提示词.md》（Ref2VA/I2VA 模式，绑定 REF 槽位）
    ↓
RunPod 跑 H3 I2VA/Ref2VA 生成视频
    ↓
抽帧检查 → 坏镜重抽 → 后期归一 → 成片
```

**成本**：单集关键帧 GPU 成本 < $0.5，同 Pod 零新平台（升级路线.md §4）。

## 1. 关键帧清单生成（分镜 → 图片提示词）

### 输入
- `docs/方案/<系列>/08-<EP>分镜.md`（含冻结关键帧、视觉依据、输入参考图）
- `docs/方案/<系列>/01-视觉设定.md`（连续性锁、造型/道具/场景规格）

### 输出
- `docs/方案/<系列>/<EP>图片提示词.md` —— 标准 `short-drama-image-prompts` 格式
- 关键帧分类：
  - **定妆帧**：每角色 1 张正脸闭嘴帧（用途：身份）
  - **首帧**：每镜 1 张起始构图帧（用途：起始帧）
  - **场景帧**：每场景 1-2 张中远景定调帧（用途：地理/风格）
  - **道具帧**：关键道具特写帧（用途：道具状态）

### 生成规则
1. **仅为需一致性的镜头生成**：手/物/环境镜无脸可漂，不绑定妆帧
2. **定妆帧标准**：正脸、五官清晰、嘴唇闭合、光照均匀、无遮挡、无第二人（方法论§7.2/§3-A5）
3. **首帧 = 冻结关键帧正文**，逐字复用，确保构图/光照/色调与分镜完全一致
4. **场景首镜出图定调**，同场景后续镜头引用同一场景帧（用途：地理/风格），只取色调光照不取构图

## 2. 参考图绑定自动化（REF 槽位管理）

### 绑定规则
从分镜 `输入参考图` 字段 + 图片提示词生成结果，自动产出标准 REF 槽位：

```
REF-<slot>（顺序：<n>）· <项目相对路径>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）
```

### 用途枚举（仅这 9 个）
| 用途 | 适用对象 | 控制范围示例 | 不得控制示例 |
|------|----------|--------------|--------------|
| 身份 | 角色定妆帧 | 五官/肤色/发型/骨骼 | 表情/姿态/服装/光照 |
| 造型状态 | 角色特定造型帧 | 服装/配饰/妆容/道具持有 | 五官/姿态/表情/光照 |
| 地理 | 场景定调帧 | 空间结构/建筑/固定装饰 | 人物/动态物体/光照细节 |
| 构图 | 首帧/关键帧 | 画面布局/主体位置/景别/机位 | 光照色调/人物微表情/动态细节 |
| 尺度 | 道具/特写帧 | 物体大小/比例/相对位置 | 材质纹理/光照/背景 |
| 效果 | 特效/氛围帧 | 烟雾/光效/色调倾向 | 具体物体结构/人物 |
| 起始帧 | 首帧 | 起始状态全貌 | 终止状态/中间过程 |
| 结束帧 | 尾帧 | 终止状态全貌 | 起始状态/中间过程 |
| 风格 | 风格参考帧 | 色调/质感/颗粒/对比度 | 具体内容/构图/人物 |

### 自动绑定流程
1. 读取分镜 `视觉依据` + `输入参考图` + `冻结关键帧提示词`
2. 匹配 `图片提示词.md` 中已生成的条目（IMG-xxx）
3. 对每镜产出 REF 槽位列表，写入 `视频提示词.md` 的 `输入参考图` 字段
4. 缺失关键帧时：标记 `待补参考图：<具体缺失>`，不降级为文生视频

## 3. 跨镜曝光/色调归一化预设

### 问题根因
H3 逐镜独立生成 → 曝光亮度/色温/对比度/饱和度随机漂移，同一场景不同镜头肉眼可见不一致。

### 归一化管线（后期自动化，build.py 集成）
```python
# 1. 基准帧选取：每场景首镜第 1 帧为基准
# 2. 计算目标统计量：均值亮度/色温/对比度/直方图
# 3. 生成 ffmpeg lut3d / colorchannelmixer / curves 参数
# 4. 批量应用：ffmpeg -i in.mp4 -vf "lut3d=file=scene01.cube" -c:a copy out.mp4
```

### 标准化预设（项目级固化，`docs/方案/<系列>/色调预设/`）
| 场景类型 | 色调关键词 | LUT/曲线参数 | 适用镜头 |
|----------|------------|--------------|----------|
| 老巷夜景 | cold cyan-grey, low key, crushed shadows | `scene_laoxiang.cube` | M01, M05, M09 |
| 室内废弃屋 | cool cyan shadows, practical light only | `scene_indoor.cube` | M02, M03, M07 |
| 符咒特写 | shallow DOF, fine film grain, gold rim | `scene_fuzhou.cube` | M04, M06, M08, M10 |
| 闪回/记忆 | warm highlight, halation, vignette | `scene_flashback.cube` | M11, M12, M13 |

**应用原则**：同场景所有镜头强制套用同一 LUT，人工仅微调 ±5% 曝光补偿。

## 4. LoRA 训练触发条件与标准流程

### 触发条件（满足任一即启动）
1. **漂移率 > 30%**（验收标准 L1#2）：抽帧检测角色/场景一致性指标超阈值
2. **跨集复用角色 ≥ 3 集**：系列级一致性需求，单集关键帧不足以支撑
3. **关键出脸镜反复重抽 ≥ 5 次不收敛**：单镜成本失控

### 训练标准流程
```bash
# 1. 数据准备（RunPod 同 Pod）
#    - 20-50 张高质量一致性图：多角度/多表情/多光照/多造型
#    - 来源：关键帧生成优选 + 成片抽帧优选 + 手工精修
#    - 命名：lora_<角色>_<角度>_<表情>_<光照>_v<版本>.png

# 2. 训练参数（固化）
#    Rank: 32, Alpha: 16, Steps: 1500, LR: 1e-4, Batch: 1
#    优化器: AdamW8bit, 学习率调度: cosine_with_restarts
#    正则化: --noise_offset 0.0357 --min_snr_gamma 5

# 3. 多角色隔离
#    每角色单独训练 LoRA，推理时分别加载，不混合
#    命名：lora_chenmo.safetensors / lora_laomo.safetensors

# 4. 验证与部署
#    生成 20 张测试图对比基线，漂移率 < 15% 才上线
#    部署：ComfyUI LoraLoader 节点加载，权重 0.8-1.0
```

### 成本估算
- 单角色训练：~2-4h GPU（4090），约 $1.5-3
- 推理开销：+10-15% 显存/时间，可接受

## 5. 工作流集成点

| 阶段 | 调用方式 | 产出 |
|------|----------|------|
| 分镜完成 | `short-drama-consistency generate-keyframes <分镜路径>` | `图片提示词.md` + 关键帧清单 JSON |
| 关键帧生成后 | `short-drama-consistency bind-refs <分镜路径> <图片提示词路径>` | 更新分镜 `输入参考图` + `视频提示词.md` REF 槽位 |
| 成片抽帧后 | `short-drama-consistency check-drift <成片目录> --threshold 0.3` | 漂移报告 JSON + 是否触发 LoRA 建议 |
| 后期归一 | `short-drama-consistency normalize <成片目录> --scene-map <场景映射>` | 归一化后成片 + LUT 应用日志 |

## 6. 验收标准（对齐验收标准.md L1/L3）

| 指标 | 合格线 | 优秀线 | 检测方式 |
|------|--------|--------|----------|
| 跨镜角色漂移率 | < 30% | < 15% | `check-drift` 人脸特征向量余弦相似度 |
| 场景色调一致性 | ΔE < 8 | ΔE < 4 | Lab 色彩空间 ΔE 计算 |
| 曝光一致性 | 亮度差 < 0.15 | 差 < 0.05 | 直方图均值相对差 |
| 道具/造型状态准确率 | 100% | 100% | 关键帧逐项核对 |
| 单集人工核查时间 | < 30min | < 15min | 计时统计 |

## 7. 常见失模式与修复（避坑指南/一致性常见坑.md 精华）

| 现象 | 根因 | 修复 | 预防 |
|------|------|------|------|
| 纯 T2VA 指望一致 | 模型无跨镜记忆 | 必须上关键帧链路 | 分镜阶段强制标注 REF 槽位 |
| 定妆帧抽错 | 说话帧/侧脸/遮挡/模糊 | 严格校验：正脸/闭嘴/清晰/无遮挡 | pick_frame.py 自动校验 |
| 场景漂移 | 无共享场景锚点 | 场景首帧出图 + 后续引用 + 后期 LUT 归一 | 视觉设定锁定场景色调 |
| 造型/道具漂移 | 无专用参考图 | 关键造型/道具单独出图绑 REF-造型/REF-道具 | 视觉设定建立状态连续性锁 |
| LoRA 过拟合/污染 | 数据少/参数错/多角色混合 | 标准流程：20-50张/角色隔离/验证上线 | LoRA 训练 SOP 文档化 |
